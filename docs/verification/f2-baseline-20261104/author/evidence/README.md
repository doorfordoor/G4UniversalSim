# F2 controlled-session baseline evidence

This directory is a disposable evidence tree for the F2 first delivery
(`F2-PROTOCOL-EVIDENCE-20261104`). It is produced by `../f2_session.py` and
summarised by `../analyze.py`; nothing here is part of the product.

## Layout

- `index.json` — every session: argv, commands, exit code, duration, run
  summary facts, per-run phase-space aggregates. Regenerated by `--all`.
- `results-summary.md`, `results.json` — tables re-derived from the raw files by
  `analyze.py`.
- `<case>/stdin.txt` — exact commands written to the audited csh session.
- `<case>/stdout.log`, `<case>/stderr.log` — raw streams (kept verbatim).
- `<case>/session.json` — the driver record (exit code, summary, rounds).
- `<case>/run_summary.txt` — product summary when the session produced one
  (`refusal-multisource` aborts before finalization and has none).
- `<case>/output/` — per-run artifacts: `phase_space_t*.csv` (kernel-consumed
  primary vertex at the Target entry boundary), `hits_t*.csv`, histograms CSV,
  `run_metadata.json`.

## Cases

| case | what it proves |
| --- | --- |
| `three-round` | same process A/B/A energy 100→200→100 MeV, kernel-consumed and Manager print agree in the managed path |
| `fields` | particle / energy / point / direction / planeBeam single-field setters take effect per round |
| `preinit-cache` | PreInit setters are cached and replayed when the GPS is created |
| `native-gps` | native `/gps/ene/mono` changes the kernel but the Manager receipt stays stale → csh cannot authorise applied values |
| `refusal-multisource` | single-source command against two named sources is rejected, subsequent commands never run, process aborts (0xC0000409) |
| `refusal-output-state` | `/AIHL/output/setDir` after `/run/initialize` is rejected by the Geant4 state gate (failed, run_count=0), subsequent commands never run |

## Reproduce

```bash
cd D:/Geant4/G4UniversalSim
G4USIM_GEANT4_DATA=D:/ProgramFiles/Geant4/share/Geant4/data \
  python -B out/collab/f2-session-baseline-20261104/f2_session.py --all
python -B out/collab/f2-session-baseline-20261104/analyze.py
```

## Boundaries

- Single thread only; multi-thread sessions are not covered.
- Windows host only; other platforms/Geant4 versions were not exercised.
- `ion`/`confine`/phase-space-file delayed application, `isotropic`, `preset`
  and `reset` are not exercised here (whitelist marks them pending).
- `refusal-multisource` aborts the process, so its "failure" is an exit code and
  stderr, not a run summary; this is itself the protocol evidence.
