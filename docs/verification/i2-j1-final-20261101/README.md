- **I2**：安装规划、受校验获取、受控前缀发布、取消/恢复、核验/卸载、runtime 与 SDK 两种方案，以及 Windows/Linux 交付流程。安装后重新发现环境，由用户显式选择。普通运行无需编译器；SDK 编译依赖单独检查。没有匹配产物清单时明确不可安装，不虚构公共下载服务。

- **用户报告的启动故障**：冻结包从 PATH 误选 Poppler 的 ICU DLL，造成 QtCore 导入失败。冻结构建已限制依赖来源并核验收集清单；正常启动/关闭、旧自检报告拒绝和早期导入失败收据均已验证。原坏包和失败证据保留。
