用户报告的 QtCore 导入失败已由 DLL 符号与打包来源证据定位；选定 Python/SystemRoot 环境和冻结 TOC 核验修复了 Poppler ICU 污染。早期把窗口关闭失败归因于 QStandardPaths 的方案已经撤回，最终遵守既有 owner 的关闭收尾，不强制删除活任务。两平台冻结桌面及辅助 Python 的 ROOT 读写和正常退出分别通过。

正式矩阵发现的测试环境问题按实际反例关闭：

- `test_platform_install_layout.py` 的临时根统一为规范路径，原布局断言不变；真实 8.3 TEMP 反例及新 Windows static CI 已通过。

- `smoke_i2_install.py` 规范 fixture 根，并在集合不等时记录实际值和期望值。真实短 TEMP 下两个候选未丢，仅拼写不同；49个原 assert 谓词/顺序与等待逻辑不变。修后当前源码59入口通过，最终6310969两平台M0工作流成功；对应原件的独立严格复核纳入最终归档。
