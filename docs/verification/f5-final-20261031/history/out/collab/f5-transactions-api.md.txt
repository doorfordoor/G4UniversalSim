- `core/edit_snapshot.py`: `EditSnapshot(project: G4USimProject, state: dict)` stores isolated typed project plus strict, bounded JSON editing state. `snapshot_to_dict(snapshot)` / `snapshot_from_dict(data)` / `snapshot_fingerprint(snapshot)`; current in-memory capture NEVER calls the legacy `project_from_dict`.
- `G4USimProject` v7 additive `materialEditor: MaterialDocument | None = None` and `editingState: dict | None = None`. None is legacy missing; explicit empty content is preserved. `editingState` uses a closed schema below, not arbitrary extensible Python values. Normal Save retains exactly the editing snapshot through these two fields.
- `editingState`: `{version: 1, drafts: {binding_name: string|bool|int}, tables: {binding_name: [[string]]}, selections: {binding_name: int}, sources: {materials|geometry: {path: str, text: str, read_success: bool, template: str}}}`. Keys/version/type/limits checked. UI validates binding names against its explicit capture registry (not `setattr` arbitrary names). `selections` are UI hints excluded from dirty fingerprint. Raw uncommitted table edit is committed to draft capture before undo/save/autosave; no model normalization for drafts.
- In-memory transient parser summaries/typed source diagnostics should be kept in `EditSnapshot.transient` (deepcopied dict; never serialized). Restore across process should derive parser summaries/typed diagnostics from persisted original text using new pure parser text functions, or root-owned restoration helper; no disk reread substituted for historical text. Existing document source errors/blockers remain persisted regardless.
- `core/edit_transactions.py`: `EditSession(initial, *, max_commands=100, max_bytes=32MiB)`; `.current` returns isolated snapshot; `.revision`, `.is_modified`, `.can_undo`, `.can_redo`, `.undo_label`, `.redo_label`; `.record(after, label, *, merge_key=None, expected_revision=None)`, `.undo()`, `.redo()`, `.reset(snapshot, *, saved=True)`, `.mark_saved(snapshot=None)`, `.break_merge()`, `.transact(label, transform, *, merge_key=None, expected_revision=None)`.
- record/undo/redo return current isolated snapshot (no-op can compare revision). `.record` records captured after using session's previous canonical before, not mutated GUI aliases. `.transact` runs transform(candidate) and commits only success, same noQt interface for future automated actions. Optional apply callback if root wants UI projection rollback coordinated before cursor publication; UI should preflight projection and call core only after controlled apply.
- Core owns project.py/project_migration.py/new edit_snapshot.py/edit_transactions.py/static tests. UI owns binding registry/capture/restore/no reload/raw delegate behavior. Recovery consumes snapshot_to_dict/from_dict and does not own transaction internals.
