## 确定为缺陷：无效 seed 草稿在 Generate 前被镜像清空，生成通过

根因链（2026-10-30 当前文件，待 UI 最终冻结核对）：
- `window/project.py:134`：Config→Project 同步 seed 采用已解析 runSettings.seed，非法草稿被镜像为 `""`。
- `window/run.py:188`：Generate 调用 `_update_project_from_page_without_preview`。
- `window/project.py:141` → `widgets/config/setup_panel.py:248`：由镜像 Project 空 seed 重新覆盖 Config 原始草稿，发生在 `run.py:200` validate_current 之前。

建议由 UI 写者保持镜像 raw seed，或在 Generate 前禁止逆向覆盖当前 Config 草稿；不要仅在测试调用 validate_current，使真正生成路径仍能绕过。验收覆盖 Config invalid seed（保存/重开/Undo后也一致）、Project invalid seed、合法 seed 与空 seed、Generate 和 Generate & Run；非法输入不得建包/启动且原始文本不丢失。此 agent 未改 UI 文件。
