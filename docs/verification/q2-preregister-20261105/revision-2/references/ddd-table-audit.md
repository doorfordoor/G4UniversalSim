## 2. 95 MeV·mb 的单位换算（算术已核验）

ASTM E722 的硅 1 MeV 中子硬度参数写作 **95 MeV·mb**（每原子位移损伤截面），转换为质量
NIEL（MeV cm²/g）：

```
95 MeV·mb = 95 × 10^-3 MeV·barn            (1 mb = 10^-3 barn)
          = 0.095 MeV·barn
1 barn    = 1 × 10^-24 cm^2
=> 95 MeV·mb = 9.5 × 10^-26 MeV·cm^2 / atom
Si 原子质量 = 28.0855 u × 1.66053906660e-27 kg/u = 4.66370e-26 kg = 4.66370e-23 g
=> 9.5e-26 / 4.66370e-23 = 2.037006e-3 MeV·cm^2/g
```

`2.037006e-3` 是**算术结果**；`95` 这个输入值本身未从 ASTM 付费全文核验（只从二手摘录/仓库
文档看到），因此不能把“与 2.037e-3 一致”当成物理正确性证明。

## 4. 为什么“约 6% 差异”不能直接判为数据/程序缺陷

1. **定义不同**：ASTM `95 MeV·mb` 是 1 MeV 中子硅损伤的**硬度参数/归一化量**，用于 NIEL
   标度；SR-NIEL 的 ASTM 模式是在其离散网格上按 ASTM damage function 计算的连续 NIEL。
   两者不是同一评价路径上的“同一点插值与真值”关系。
2. **评价与版本**：SR-NIEL 表由 ASTM damage function 数据生成，网格/截断/插值约定由该服务
   定义；不同版本（SR-NIEL-7 vs 更早）和不同 Ed（硅 21 eV 以外）会改变数值。
3. **网格与插值**：缺 1.000 MeV 节点导致 log-log/线性差异（上表）；若按 ASTM 网格重采样，
   结果也会变化。
4. **输入未核验**：`95` 输入值未从权威全文核对，不能拿它做 0.1% 级别的判据。

因此本文件**不设**“1 MeV 插值必须与 95 MeV·mb 在 0.1% 内一致”的判据，也不补点强行吻合。
可判定的只有：表头/单位/单调/有限非负、插值算法可复算、与公开 ASTM 摘要适用范围一致；
物理一致性判定需同时满足“模型、Ed、标准版本与数值输入均有据”三者，当前不满足。
