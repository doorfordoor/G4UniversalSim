## 2. 125% / 150% 显示缩放

- 125%：`QT_SCALE_FACTOR=1.25`，1560×980 逻辑窗口，抓图 1950×1225；配置页三个面板完整，
  无横向裁剪（`screens/scale-125-paper-configuration.png`）。
- 150%：`QT_SCALE_FACTOR=1.5`，1280×800 逻辑窗口，抓图 2400×1500；**发现窗口实际被撑到约
  1600 逻辑宽（左侧栏 + 配置 dock 最小宽 + 3D dock 最小宽之和），超过 1920×1080 屏幕在 150%
  下的 1280 逻辑宽，右侧 3D 面板被屏幕裁掉**（`screens/scale-150-paper-configuration.png`）。
  这不是主题问题，而是工作区最小宽度问题：窗口不能缩小到屏幕宽度。当前代码新增
  `WorkspaceLayout.adapt_to_width()`（窄窗口时收窄 setup 面板、图例与 dock 尺寸）与
  `PyVistaPreviewWidget.set_compact()`，但只在窗口实际宽度 < 1400 时生效，150% + 1280 屏幕
  仍被最小宽度卡住；彻底修复需要降低工作区最小宽度（下一步工作）。
- 结论：125% 通过；150% 记录为**已知缺陷**，未修复、未验收。Linux 真实桌面实窗与主题切换
  性能基线仍待做。
