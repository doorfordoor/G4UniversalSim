- 默认显示只读、可鼠标/键盘选择复制的 `summary` 文本区，使用 WidgetWidth 与 WrapAtWordBoundaryOrAnywhere：长路径完整保留且可换行，不省略；摘要包含当前后端、原探测状态、架构、Geant4 版本、编译器、必需数据情况及选择边界。
- 后端数值版本 1132 仅显示格式化为 11.3.2；原 facts 和 JSON 仍是 1132。缺失版本显示 Unknown。没有据版本决定支持状态。
- 必需数据情况只展示 discovery 提供的 required_complete 真/假/未知；缺报告也明确未知，不能由总体 ready 反推数据完备。报告中 required=true 且 found=false 的数据集列出完整名称；可选缺失不混入必需缺失。未重判状态、未读取目录或额外探测。
- 原始 JSON 放在默认收起的“技术详情”下，`details` 仍为原 QPlainTextEdit，toPlainText() 和全部原始协议内容继续兼容；选择不同候选同步更新摘要与 JSON。空列表/刷新清空旧摘要，原异步 worker、generation 防旧回执、close/delete、busy 和选定条件保留。
- 表格取消编译器末列自动拉伸，路径至少 300、状态至少 240（随完整状态文字测量增加），架构/版本各 80、编译器 150；多余宽度分给路径和状态。所有单元格 tooltip 是完整值。窄窗口保留横向滚动，摘要自身可纵向滚动且路径换行。
- 按钮按实际字体宽度在一/两列间排列，避免按钮最小宽度阻止窗口缩到 480。`retranslate_ui()` 更新标题、表头、按钮、单元格、提示及摘要，沿用集中 ui_text/ui_format，无新增翻译系统。
- 选择仍仅允许 capabilities available 且 identity.stable true；数据不完整时仍允许选路径，动作不启动模拟。environment_selected 的原事实副本、selected_environment / selected_executable 与已有生命周期保持原语义。
