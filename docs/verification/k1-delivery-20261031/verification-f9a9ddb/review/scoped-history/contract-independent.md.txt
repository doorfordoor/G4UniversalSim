## 建议立即裁决的五件事

1. 配置包区分原始资源字节身份、重定位后可执行输入身份、历史验证身份；重写路径不是原 hash 的延续。搬移可保留历史可读性，不能自动继承本机验证。
2. 指定输入完成的判断必须连接“本次请求 → 实际启动命令与输入 → F1 读入序列 → 本次 execution_id → 逐 run 事实”；仅 run_result success 或 manifest 自洽均不够。
3. 外部 macro 的未知命令/未知资源语法默认不能取得完整闭包与可信重放资格；原后端 preflight 可通过，不等于 K1 可分发。
4. 当前验证资格至少绑定会话身份、单调编辑 revision、输入内容与执行/判据身份；Undo 回到相同内容仍须新验证，迟到回调不能恢复绿色。
5. 包采用专门的可移植导出投影，不能直接把完整 F5 恢复快照或 package snapshot 当作可分发配置。保留草稿语义与禁止导出机器设置之间需要显式转换规则。

## 12 个具体反例与验收判据

### 1. 搬移 hash：路径改写成功，却沿用旧验证为当前有效（P1）

**构造**：A 目录运行成功，主 INI 引用绝对 geometry/STL 路径。导出时改成包内相对路径，移到含中文/空格的 B 目录，并让 A 不可访问；再加载 B。变体：项目 v7 的 source_path/raw_source_text 中仍藏 A，或 exporter 在 B 重写 INI 后仍保存 A 时的 SHA。

**必须判定**：只搬目录且成员字节未改，成员 SHA 不变；改写 INI/macro 后必须记录新的 SHA，并保留原字节 → 新字节的重定位映射。历史收据原样保留并标历史/待本机重验，不重算历史 SHA 来伪造其原来读过 B。重放只能读当前包根内经清单验证的成员；旧根可访问也不得回退读取。关闭 A 后仍能完成允许范围内的重放，是资源可移植性的必要负向对照。

**可借用**：`gui/g4usim_gui/output/provenance.py:131`、`:148` 已从旧 manifest 锚点映射到当前结果根；`:158` 检查解析后仍在当前根。`gui/g4usim_gui/writers/main_ini_writer.py:93`、`:97`、`:101` 现写入 output/material/geometry 的包路径，不能假定其输出天然可搬移。**边界**：F1 输出重定位可借用原则，不直接代替 K1 输入映射协议。

### 2. 实际资源 vs 计划文件：导出清单全对，但模拟读了另一版本（P1）

**构造**：生成时表/谱/STL 为 H1；启动前换为同名、同长度、尽量同 mtime 的 H2；或先读 H1、第二次读 H2，结束前恢复 H1。另用 CRLF/BOM 差异证明逻辑文本 SHA 相同或不同不能代替原始字节 SHA。编辑快照不变，资源在磁盘已变。

**必须判定**：生成/导出计划 SHA、实际读取 SHA、配置语义接受/内核应用分别保存。指定输入的运行验证不得在任一相关实际读取与预期不一致时通过；不能将多次读取按 path 压成最后一条，不能在结束后重读磁盘补历史。F1 的 unobserved 必须保留原因并限制对应结论；“所有计划文件都 hash 过”不证明完整实际依赖已观测。无关计划成员未被读取不直接算失败，要按资源角色和本验证阶段解释。

**可借用**：`src/Config/InputProvenance.cc:115` 从一次二进制读取返回被解析的 bytes 并登记；`:86` 追加读取、`:94` 登记 unobserved。`gui/g4usim_gui/output/identity.py:59` 明确仅 project readers、bytes read 非语义接受，`:65` 校验连续序列。具体资源入口：`src/Geometry/StlReader.cc:76`、`src/Source/SourceManager.cc:177`、`src/Scoring/NielTable.cc:15`、`src/Scoring/PhaseSpace.cc:71`。`gui/g4usim_gui/core/diagnostics.py:79` 的 SHA 是 UTF-8 逻辑文本，不能充当这些原始字节收据。

### 3. Inspect 返回零、甚至宏中写了 initialize，就显示“初始化已验证”（P1）

**构造**：macro 包含 `/run/initialize`；`--inspect-run` Configure/preflight 成功，但真实初始化时缺 Geant4 数据、构造资源不合法或几何检查失败。再加一个只有 initialize、没有 beamOn 的正常零事件进程。

**必须判定**：Inspect 只发布字段/配置与 preflight 层结果；宏文本含 initialize 不算执行证据。初始化/几何检查必须实际执行对应入口并保留阶段证据；未运行几何检查就不能写“几何通过”。只有初始化的零事件结果可以支持已证实的初始化层，不能升级为指定输入事件完成；无 run、dry-run 与 success 分开。生成的 validation_report/diagnostics 也只证明生成入口的校验。

**可借用**：`main.cc:624`、`:629`、`:640`、`:644` 是 Inspect 的 Configure/preflight/计划输出路径；帮助说明 `main.cc:280` 明说无初始化/执行。`gui/g4usim_gui/core/run_result.py:83`、`:89`、`:91` 已区分 dry-run/no-run/正事件完成。`gui/g4usim_gui/writers/package_writer.py:104` 的报告不能升格为后端执行收据。

### 4. 外部 macro 隐藏 I/O：递归 execute 收齐了，仍遗漏数据或副作用（P1）

**构造**：顶层 macro 引用子目录 macro，子 macro 使用受支持的 RNG 恢复或原生读文件命令；再加入未建模的原生命令/自定义命令，其参数指向另一个文件或产生输出。只收集 `/control/execute` 的打包器仍可对所有已知成员给出完整 SHA。GDML 引用外部依赖/网络也是同类闭包反例。

**必须判定**：递归 macro 文件、命令资源参数和其嵌套依赖是不同层次。仅对已知语法给出闭包；未知命令不能因“未发现路径”当成无 I/O。可信导出/重放须拒绝或走明确的资源/执行策略，受限导出必须说清无法证明的部分，不能仍显示完整可信。顶层按工作目录、嵌套 execute 按发出 macro 的目录解析；不要将这条规则未经核实套到其他命令的文件参数。已拒绝的动态 alias/loop/if 不能在 K1 旁路展开。含输出/外部副作用的命令也需独立处理，输入 hash 不提供执行隔离。

**可借用**：`src/Core/MacroPreflight.cc:265` 只拒绝列明动态命令；`:301` 对其他非 execute 命令保留执行序列，**不是 I/O 白名单**；`:307`、`:310` 才是递归 execute 解析。`src/Geometry/GdmlInputCapture.cc:171`、`:204` 能表达部分网络流未观测，不能由此声称离线依赖闭合。

### 5. 同事件计数、同名文件，却是另一次运行；取消后迟到成功（P1）

**构造**：A/B 都完成 100 事件、runID=0，seed/几何不同。B 的目录被放入 A 完整且自洽的摘要和 metadata，或 A 的 finished 回调落到 B 当前记录。另构造逐轮 planned=(40,60)、completed=(30,70)，总数仍 100；取消与正常 finished 接近同时到达。

**必须判定**：run_result 的正常退出/新摘要/逐轮完成是必要条件；还须核对本次请求、独立输出目录、本次实际 F1 execution_id、输入与执行身份。验证记录以 `(execution_id, run_id)` 等明确作用域关联数据，不能只比较总 N 或文件名。完整替换为另一份有效 F1 结果仍须由请求关联检测；单独 F1 自洽不是来源认证。取消/kill 请求已生效后不得发布 success，旧回调不得覆盖新请求；忙时拒绝不能先创建一个看似已启动的成功记录。

**可借用**：`gui/g4usim_gui/core/run_result.py:27` 逐 run 核对，`:52` 终止请求优先。`gui/g4usim_gui/core/runner.py:85` 忙时拒绝，`:131`、`:141` 锁存终止，`:224` 仅用 mtime/size 判断摘要 fresh，**不能作为 K1 强身份**。`gui/g4usim_gui/output/identity.py:43`、`:76` 校验 execution 与 artifact 作用域；它证明记录内部一致，不独自证明来自当前 QProcess。

### 6. 物理比较：数值接近，实际比较了不同量或不同归一化（P1）

**构造**：参考为每事件 Gy，结果为总 Gy，刚好某个 N 使数值落容差；一个事件含多个初级粒子，却按事件数叫“每初级粒子”；对 LET 比值再除 N；把 raw 与 weighted 沉积混比，或拿 run0 的统计量比较 run1 的参考。

**必须判定**：比较规格必须显式绑定量、单位/换算、总量或 per-event、raw/weighted、对象/体积、run、参考字节及出处、预先固定的判据。口径未知/矛盾时报告不可比较，不能默认为通过。判据变更产生新的评估记录，不能改历史容差直到过关。物理通过只限这个明确比较，不提升为普遍物理正确。

**可借用**：`gui/g4usim_gui/output/plot_data.py:409` 限定 total/per_event，`:412` 拒绝 LET 再归一化，`:416` 使用对应 run 的已完成事件。`gui/g4usim_gui/output/dose_summary.py:39`、`:43` 分 raw/weighted。图可绘制并不表示已有通用物理比较服务；K1 应复用定义而非复用“画出了图”作为验收。

### 7. 统计比较：稀疏 worker 的行数被当成完整 N，未知误差被填零（P1）

**构造**：master 完成 N=100，某 worker 只有 3 个发生沉积的事件行，另一个只有表头；把去重可见 eventID=3 当 N，或者把只有一次事件/零总量的 sigma 填 0。两个 mesh cell 相加时直接平方合并误差，尽管未存跨 cell 协方差。

**必须判定**：完整 N 取可靠 master/run metadata；稀疏 worker 去重计数只是下界，空表头 N 未知，不能强行要求每 worker N 等于 master N。估计方法、uncertainty_status 与统计单位必须进入评估证据。依赖 sigma 的判据在 N<2/零分母/未知协方差时不可评估，不能“零误差通过”。若独立固定确定性容差不使用 sigma，应按该独立判据评估，并保留误差不可用事实；不必笼统拒绝所有比较。

**可借用**：`gui/g4usim_gui/output/plot_data.py:149`、`:158`、`:163` 明确保守不确定度状态；`:264`、`:298` 明确跨 cell 协方差未知；`:374` 从对应 run 取完整 N。`docs/agent-history.md:540` 保留 F5 稀疏 worker 下界与空表头反例，不重复错误的强等 N 假设。

### 11. 导出“完整快照”同时泄漏机器设置，或清理快照后破坏来源语义（P1）

**构造**：在隔离夹具的 QSettings、环境变量、executable/workspaceRoot/pathSettings、editingState.sources 与历史 command/log 字段分别放入不同的假凭据/私有路径哨兵；配置包通过复制完整项目/恢复载荷或递归复制工作目录把它们带出。反向变体：为去路径清空 raw_source_text/source_path，导致原本阻断的非法源被恢复为可运行。

**必须判定**：专门定义可移植字段允许表和重定位规则；包不得含密钥、用户设置、完整环境变量、二进制或可执行的原机器选择。扫描所有递归成员（项目、编辑来源、验证历史、重放脚本和说明），不仅顶层 JSON。用人工假哨兵验收，不读真实密钥。历史环境只留必要的非敏感事实，路径按规则脱敏/相对化，并明确不改变原始历史的证明边界。若无法同时保留合法编辑/阻断语义与禁止内容，就拒绝导出或使用显式受限策略，不能静默删字段后冒称完整恢复。资源分发权 unknown 要保留，不等于授权许可。

### 12. Manifest 局部正确/发布一半：加载接受逃逸或导出覆盖已有目标（P1）
