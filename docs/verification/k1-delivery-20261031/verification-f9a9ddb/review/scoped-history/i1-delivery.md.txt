## 可直接接线的接口

```python
from g4usim_gui.core.environment_discovery import discover_environments, probe_environment

facts = discover_environments(candidates=[
    executable,
    {"executable": other_executable, "label": "另一环境",
     "env": {"GEANT4_DATA_DIR": other_data, "LD_LIBRARY_PATH": other_lib},
     "sdk_roots": [other_sdk]},
], timeout=5.0, env=None, sdk_roots=())
one = probe_environment(executable, timeout=5.0, env=None, sdk_roots=())
```

两个返回值都是可 `json.dumps(..., allow_nan=False)` 的字典。单环境协议 `g4usim_environment_v1`；集合协议 `g4usim_environment_discovery_v1`。集合包含 `environments`、`host`、`sdk`。单环境包含 `executable/status/capabilities/data/identity/architecture/build/sdk/diagnostics`。`candidates=None` 仅发现 G4USIM_EXE/PATH；`[]` 只做主机依赖诊断，不扫描后端。相同路径及覆盖去重，不同子环境覆盖保留。覆盖只传给子进程，不序列化完整环境。

能力通过真实 `--capabilities` 查询并复用 BackendCapabilities.from_json 校验；数据通过真实 `--check-geant4-data`，结构、逐项状态、汇总和退出码共同校验。没有内置数据版本表，也没有假定目录存在就物理可用。能力与数据命令独立，即便前者失败仍保存后者证据。

`ready` 仅指能力协议可读、必需数据目录完整、二进制探测前后 SHA 相同。数据内容、初始化、实际事件和物理比较不在此状态含义内。其余状态区分 data_incomplete、partial、unavailable、not_found、error 和 changed_during_probe。命令单独保留 timeout/spawn_error/missing_library/loader_error/protocol_error/output_limit/invalid_encoding、真实退出码、耗时、stderr；超时回收直接子进程，未声称终止任意后代。输出返回有 4 MiB 限制，stderr 有长度限制。

二进制 PE/ELF 架构来自文件头，与主机/Python 位数分开。未知格式保持 unknown。SDK 仅报告显式根/环境线索的配置及头文件存在，build_verified=false。host.tools 与后端构建编译器分开，记录 CMake/编译器版本命令事实。可选 Python 组件只 find_spec/发行版本，不导入，import_tested=false；GDML 等后端能力保持原协议事实。无 Qt、Geant4 或后端也能 import 核心并读取诊断。

```python
from g4usim_gui.widgets.environment_dialog import EnvironmentDialog

dialog = EnvironmentDialog(candidates=[executable], parent=parent)
dialog.environment_selected.connect(on_selected_facts)
dialog.open()  # 或 show()；调用方按既有窗口生命周期保留实例
# 接受后：dialog.selected_environment() / dialog.selected_executable()
```

`environment_selected(dict)`、两个 getter 都给接受后的选择；高亮行不接受选择。能力可读、字节前后稳定才允许选择；缺数据仍可选路径并显示警示，由既有 runner 继续运行前校验。对话框使用全局 Qt 线程池和显式 QueuedConnection；刷新期间旧行失效，重复刷新不排队，窗口关闭不等待探测。关闭/删除/旧请求的结果不得发布。工作线程仅调用独立发现服务，未引入新进程控制器。没有自动安装、修复、修改项目或启动模拟。
