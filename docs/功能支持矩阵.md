## 1. 支持等级定义

证据类型（本文件统一口径，用于说明“凭什么认为它成立”）：

| 证据类型 | 含义 |
| --- | --- |
| 外部表 | 与仓库外的独立权威数据比较：NIST PSTAR/ESTAR/XCOM、SR-NIEL、PDG、NNDC。 |
| 解析式 | 与解析公式或解析解比较：Bethe、Klein–Nishina、圆轨迹、实体体积公式、GPS 抽样统计期望。 |
| 同源自洽 | 两个实现互相验证：ROOT 与同 run CSV、Geant4 原生 scorer 与项目 scorer、独立重算 hits、相空间重放。它证明实现一致，不证明物理正确。 |
| 自测 | 只有本仓库的自动化断言：配置校验、命令状态门禁、文件数据契约、生命周期、GUI round-trip。不含外部物理参考。 |
| 未验证 | 运行时路径存在，但物理效果或实际偏差尚未观测（例如未观测到偏置权重、未与实测效率比较）。 |

第 2–3 节每条功能的事实列末尾标出它的证据类型；只给“完整支持/部分支持”而不给证据类型时，不得据此推断物理已验证。

| 等级 | 判定规则 |
| --- | --- |
| 完整支持 | 后端完成配置/命令解析、校验和运行时行为，结果或状态有明确输出，并有相应测试或 smoke 证据。 |
| 部分支持 | 只完成部分入口或运行路径，存在实验性限制、未闭合依赖、有限形状/分布、手工后处理或物理结果尚未验证。 |
| 未支持 | 后端没有运行时实现，或者只是占位/空实现；解析成功、GUI 显示或类已注册不改变此等级。 |

GUI 的“可编辑”不提升后端支持等级；GUI 只支持后端已经实现且 writer/validator 能正确闭环的子集。

## 4. 状态变更门槛
