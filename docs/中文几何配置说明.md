# G4UniversalSim 中文几何配置说明

本文档说明当前项目中 Geometry 模块的真实配置写法，以及每个几何模板实际会生成哪些形状。内容基于当前源码：

- `src/Templates/*.cc`
- `src/Geometry/GeometryConfig.cc`
- `src/Geometry/VolumeBuilder.cc`
- `src/Geometry/GeometryMessenger.cc`
- `config/geometry/*.ini`

如果早期说明或示例与本文不一致，以当前源码和本文为准。

## 1. 几何加载流程

常规流程是：

```tcl
/AIHL/material/load config/materials/material.ini
/AIHL/geometry/setTemplate simple_box
/AIHL/geometry/loadConfig config/geometry/simple_box.ini
/AIHL/geometry/printTree
/run/initialize
```

对应代码路径：

1. `/AIHL/geometry/setTemplate` 设置模板名。
2. `/AIHL/geometry/loadConfig` 调用 `GeometryManager::LoadGeometryConfig()`。
3. `TemplateFactory` 根据模板名创建模板类。
4. 模板读取 ini，生成 `VolumeNode` 树。
5. `/run/initialize` 时 `DetectorConstruction::Construct()` 调用 `GeometryManager::BuildWorld()`。
6. `VolumeBuilder` 把 `VolumeNode` 树转换为 Geant4 的 `G4Solid / G4LogicalVolume / G4PVPlacement`。

注意：`loadConfig` 只修改几何树，不直接创建 Geant4 几何对象。运行初始化后再修改几何时，需要执行：

```tcl
/run/reinitializeGeometry
```

## 2. 模板列表

当前 `TemplateFactory` 支持以下模板名：

| 模板名 | 别名 | 配置示例 | 当前状态 |
|---|---|---|---|
| `simple_box` | `simple` | `config/geometry/simple_box.ini` | 可用 |
| `layered_device` | `layered` | `config/geometry/layered_device.ini` | 可用 |
| `hierarchical` | 无 | `config/geometry/hierarchical_volume.ini` | 可用，通用树配置 |
| `array` | 无 | `config/geometry/array.ini` | 可用 |
| `shielding` | 无 | `config/geometry/shielding.ini` | 可用 |
| `gdml` | 无 | `config/geometry/gdml_import.ini` | 仅占位解析，尚未真正导入 GDML |

## 3. 单位与向量格式

几何长度使用 `UnitParser::ParseLength()`，角度使用 `UnitParser::ParseAngle()`。

常用长度单位示例：

```ini
1 nm
100 um
1 mm
2.5 cm
1 m
```

常用角度单位示例：

```ini
0 deg
90 deg
3.14159 rad
```

三维向量可以写成逗号格式：

```ini
size = 10 cm, 10 cm, 10 cm
position = 0 mm, 0 mm, 2 cm
rotation = 0 deg, 0 deg, 0 deg
```

也支持部分空格格式，例如：

```ini
size = 10 cm 10 cm 10 cm
position = 0 mm 0 mm 2 cm
```

为了减少歧义，推荐统一使用逗号格式。

## 4. 当前真正可构建的形状

`GeometryUtils::ParseShape()` 能识别若干形状名，但最终是否可构建由 `VolumeBuilder::CreateSolid()` 决定。

| shape 写法 | Geant4 solid | 参数要求 | 当前状态 |
|---|---|---|---|
| `box`, `cube` | `G4Box` | `size = x, y, z`，三者均为完整边长 | 可用 |
| `tubs`, `tube`, `cylinder` | `G4Tubs` | `parameters = rMin, rMax, halfZ, startPhi, deltaPhi` | 可用 |
| `sphere` | `G4Sphere` | `parameters = rMin, rMax, startPhi, deltaPhi, startTheta, deltaTheta` | 可用 |
| `orb` | `G4Orb` | 推荐 `parameters = radius` | 可用 |
| `cone`, `cons` | `G4Cons` | `parameters = rMin1, rMax1, rMin2, rMax2, halfZ, startPhi, deltaPhi` | 可用 |
| `trap`, `trapezoid` | 无 | 无 | 解析器识别，但 `VolumeBuilder` 尚未实现，不能使用 |

### 4.1 box

```ini
[volume.Detector]
parent = world
shape = box
size = 1 cm, 1 cm, 1 mm
material = G4_Si
position = 0 mm, 0 mm, 0 mm
```

`size` 是完整尺寸，`VolumeBuilder` 内部会传给 `G4Box` 半长：

```cpp
G4Box(name, size.x * 0.5, size.y * 0.5, size.z * 0.5)
```

### 4.2 tubs / cylinder

```ini
[volume.Cylinder]
parent = world
shape = tubs
parameters = 0 mm, 5 mm, 10 mm, 0 deg, 360 deg
material = G4_WATER
position = 0 mm, 0 mm, 0 mm
```

参数顺序固定为：

```text
rMin, rMax, halfZ, startPhi, deltaPhi
```

其中 `halfZ` 是半高，不是完整高度。

### 4.3 sphere

```ini
[volume.Shell]
parent = world
shape = sphere
parameters = 0 mm, 5 mm, 0 deg, 360 deg, 0 deg, 180 deg
material = G4_WATER
```

参数顺序固定为：

```text
rMin, rMax, startPhi, deltaPhi, startTheta, deltaTheta
```

### 4.4 orb

```ini
[volume.Ball]
parent = world
shape = orb
parameters = 5 mm
material = G4_WATER
```

`orb` 是完整实心球，只有一个半径参数。

### 4.5 cone / cons

```ini
[volume.Cone]
parent = world
shape = cone
parameters = 0 mm, 5 mm, 0 mm, 2 mm, 10 mm, 0 deg, 360 deg
material = G4_Si
```

参数顺序固定为：

```text
rMin1, rMax1, rMin2, rMax2, halfZ, startPhi, deltaPhi
```

### 4.6 trapezoid

`trap` / `trapezoid` 当前只被 `ParseShape()` 识别，`VolumeBuilder` 没有创建 `G4Trap` 的实现。不要在配置文件中使用，否则构建几何时会失败。

## 5. 通用层级几何写法

`hierarchical` 模板使用 `GeometryConfig` 解析通用 `[world]` 和 `[volume.*]` section。它是当前最灵活的几何配置方式。

### 5.1 基本格式

```ini
[world]
shape = box
size = 10 cm, 10 cm, 10 cm
material = G4_AIR

[volume.Container]
parent = world
shape = box
size = 5 cm, 5 cm, 5 cm
material = G4_WATER
position = 0 mm, 0 mm, 0 mm

[volume.Detector]
parent = Container
shape = box
size = 1 cm, 1 cm, 1 cm
material = G4_Si
position = 0 mm, 0 mm, 0 mm
sensitive = true
region = DetectorRegion
```

### 5.2 通用 key 表

| key | 适用范围 | 含义 | 是否必需 |
|---|---|---|---|
| `name` | `[world]`, `[volume.*]` | 体积名；省略时使用 section 名 | 可选 |
| `parent` | `[volume.*]` | 母体积名称 | 子体积必需 |
| `shape` | 所有体积 | 形状：`box/tubs/sphere/orb/cone` 等 | 必需 |
| `size` | `box` | 完整尺寸 `x,y,z` | box 必需 |
| `parameters` | `tubs/sphere/orb/cone` | 形状参数列表 | 对参数形状必需 |
| `material` | 所有体积 | 材料名，来自 MaterialManager 或 NIST | 必需 |
| `position` | 子体积 | 相对母体积的位置 | 可选，默认 0 |
| `rotation` | 子体积 | 绕 x/y/z 的旋转角 | 可选，默认 0 |
| `sensitive` | 子体积 | 是否注册为 sensitive volume | 可选，默认 false |
| `bias` | 子体积 | 是否注册为 bias volume | 可选，默认 false |
| `region` | 子体积 | Geant4 region 名称 | 可选 |
| `cut.gamma` | 带 region 的体积 | gamma production cut | 可选 |
| `cut.e-` | 带 region 的体积 | electron production cut | 可选 |
| `cut.e+` | 带 region 的体积 | positron production cut | 可选 |
| `cut.proton` | 带 region 的体积 | proton production cut | 可选 |
| `vis.color` | 所有体积 | 可视化颜色 | 可选 |
| `vis.alpha` | 所有体积 | 透明度 | 可选 |
| `vis.visible` | 所有体积 | 是否可见 | 可选 |
| `vis.wireframe` | 所有体积 | 是否线框 | 可选 |
| `placement` | 所有体积 | 解析为 placement 类型 | 当前构建器仍按普通 `G4PVPlacement` 放置 |
| `copyNo` | 子体积 | copy number，作为额外属性读取 | 可选 |

`GeometryConfig` 会把未知 key 保存到 `VolumeNode::userProperties`。当前 `VolumeBuilder` 已使用的额外属性只有 `copyNo`，其他未知 key 不会自动影响几何构建。

### 5.3 示例：混合形状层级几何

```ini
[world]
shape = box
size = 20 cm, 20 cm, 20 cm
material = G4_AIR

[volume.BoxDetector]
parent = world
shape = box
size = 1 cm, 1 cm, 1 mm
material = G4_Si
position = -2 cm, 0 mm, 0 mm
sensitive = true
region = BoxRegion

[volume.WaterCylinder]
parent = world
shape = tubs
parameters = 0 mm, 5 mm, 10 mm, 0 deg, 360 deg
material = G4_WATER
position = 0 mm, 0 mm, 0 mm

[volume.SphereDetector]
parent = world
shape = sphere
parameters = 0 mm, 5 mm, 0 deg, 360 deg, 0 deg, 180 deg
material = G4_WATER
position = 2 cm, 0 mm, 0 mm
```

运行方式：

```tcl
/AIHL/geometry/setTemplate hierarchical
/AIHL/geometry/loadConfig config/geometry/hierarchical_volume.ini
```

## 6. simple_box 模板

示例文件：

```text
config/geometry/simple_box.ini
```

### 6.1 实际生成形状

`simple_box` 会生成：

1. 一个名为 `world` 的 `box`。
2. 一个放在 `world` 内的 target。

当前实现中 world 一定是 `box`。target 默认是 `box`，虽然配置里有 `shape` 字段，但模板只读取 `size`，不读取通用 `parameters`。因此推荐 target 使用 `shape = box`。如果需要 `tubs/sphere/cone` 等参数形状，请使用 `hierarchical` 模板或 `/AIHL/geometry/addVolume`。

### 6.2 必需配置

```ini
[world]
size = 10 cm, 10 cm, 10 cm
material = G4_AIR

[target]
size = 1 cm, 1 cm, 1 mm
material = G4_Si
```

### 6.3 完整示例

```ini
[world]
size = 10 cm, 10 cm, 10 cm
material = G4_AIR

[target]
name = Target
shape = box
size = 1 cm, 1 cm, 1 mm
material = G4_Si
position = 0 mm, 0 mm, 0 mm
rotation = 0 deg, 0 deg, 0 deg
sensitive = true
bias = false
region = SV
cut.gamma = 1 um
cut.e- = 1 um
cut.e+ = 1 um
cut.proton = 1 um

[visual.world]
color = white
alpha = 0.05
visible = true
wireframe = true

[visual.target]
color = blue
alpha = 0.6
visible = true
wireframe = false
```

### 6.4 simple_box 支持的 key

`[world]`：

| key | 含义 | 默认值 |
|---|---|---|
| `size` | world 的 box 完整尺寸 | 必需 |
| `material` | world 材料 | 必需 |

`[target]`：

| key | 含义 | 默认值 |
|---|---|---|
| `name` | target 名称 | `Target` |
| `shape` | target 形状，推荐 `box` | `box` |
| `size` | target 完整尺寸 | 必需 |
| `material` | target 材料 | 必需 |
| `position` | target 位置 | `0 mm, 0 mm, 0 mm` |
| `rotation` | target 旋转 | `0 deg, 0 deg, 0 deg` |
| `sensitive` | 是否 sensitive | `true` |
| `bias` | 是否 bias volume | `false` |
| `region` | region 名 | 空 |
| `cut.gamma` | gamma cut | 可选 |
| `cut.e-` | electron cut | 可选 |
| `cut.e+` | positron cut | 可选 |
| `cut.proton` | proton cut | 可选 |

`[visual.world]` / `[visual.target]`：

| key | 含义 |
|---|---|
| `color` | `white/black/red/green/blue/yellow/cyan/magenta/gray/grey` |
| `alpha` | 透明度 |
| `visible` | 是否显示 |
| `wireframe` | 是否线框 |

## 7. layered_device 模板

示例文件：

```text
config/geometry/layered_device.ini
```

### 7.1 实际生成形状

`layered_device` 会生成：

1. 一个名为 `world` 的 `box`。
2. 多个沿 z 方向堆叠的 layer，每个 layer 都是 `box`。

当前只支持 `axis = z`。每层的 `size` 由：

```text
x = xy 的第一个长度
y = xy 的第二个长度
z = thickness
```

### 7.2 必需配置

```ini
[world]
size = 20 cm, 20 cm, 20 cm
material = G4_AIR

[layers]
count = 3
names = Substrate, Oxide, Metal

[layer.Substrate]
thickness = 500 um
xy = 10 mm, 10 mm
material = G4_Si
```

每个 `names` 中的 layer 都必须有对应 `[layer.Name]` section，并提供：

- `thickness`
- `xy`
- `material`

### 7.3 完整示例

```ini
[world]
size = 20 cm, 20 cm, 20 cm
material = G4_AIR

[layers]
count = 3
names = Substrate, Oxide, Metal
auto_stack = true
axis = z
gap = 0 um

[layer.Substrate]
thickness = 500 um
xy = 10 mm, 10 mm
material = G4_Si
sensitive = false
bias = false
region = SubstrateRegion

[layer.Oxide]
thickness = 1 um
xy = 10 mm, 10 mm
material = G4_WATER
sensitive = true
bias = false
region = OxideRegion
cut.e- = 100 nm

[layer.Metal]
thickness = 2 um
xy = 10 mm, 10 mm
material = G4_Cu
sensitive = true
bias = true
region = MetalRegion
```

### 7.4 layered_device 支持的 key

`[layers]`：

| key | 含义 | 默认值 |
|---|---|---|
| `count` | layer 数量 | 必需 |
| `names` | layer 名称列表 | 必需 |
| `auto_stack` | 是否自动沿 z 堆叠 | `true` |
| `axis` | 堆叠轴 | `z`，当前只支持 z |
| `gap` | 层间间隔 | `0` |
| `z_start` | 自动堆叠起始 z 边界 | 不写时居中堆叠 |

`[layer.Name]`：

| key | 含义 | 默认值 |
|---|---|---|
| `thickness` | z 方向厚度 | 必需 |
| `xy` | x/y 完整尺寸 | 必需 |
| `material` | 材料 | 必需 |
| `position` | `auto_stack=false` 时使用 | 无 |
| `rotation` | 旋转 | `0 deg, 0 deg, 0 deg` |
| `sensitive` | 是否 sensitive | `false` |
| `bias` | 是否 bias volume | `false` |
| `region` | region 名 | 空 |
| `cut.gamma` | gamma cut | 可选 |
| `cut.e-` | electron cut | 可选 |
| `cut.e+` | positron cut | 可选 |
| `cut.proton` | proton cut | 可选 |
| `vis.color` | 可视化颜色 | 可选 |
| `vis.alpha` | 透明度 | 可选 |
| `vis.visible` | 是否显示 | 可选 |
| `vis.wireframe` | 是否线框 | 可选 |

## 8. hierarchical 模板

示例文件：

```text
config/geometry/hierarchical_volume.ini
```

### 8.1 实际生成形状

`hierarchical` 不规定固定几何形态，而是直接使用通用 `[world]` 和 `[volume.*]` 配置生成树。

它是当前推荐用于复杂几何的模板，因为它能表达：

- 多级父子体积；
- `box/tubs/sphere/orb/cone` 等参数形状；
- sensitive / bias / region；
- production cuts；
- 可视化属性。

### 8.2 示例

```ini
[world]
shape = box
size = 10 cm, 10 cm, 10 cm
material = G4_AIR

[volume.Container]
parent = world
shape = box
size = 5 cm, 5 cm, 5 cm
material = G4_WATER
position = 0 mm, 0 mm, 0 mm

[volume.Detector]
parent = Container
shape = box
size = 1 cm, 1 cm, 1 cm
material = G4_Si
position = 0 mm, 0 mm, 0 mm
sensitive = true
region = DetectorRegion
```

## 9. array 模板

示例文件：

```text
config/geometry/array.ini
```

### 9.1 实际生成形状

`array` 会生成：

1. 一个名为 `world` 的 `box`。
2. 一个规则三维阵列，元素名称格式为：

```text
<name>_<i>_<j>_<k>
```

例如：

```text
PixelArray_0_0_0
PixelArray_1_0_0
```

阵列元素默认是 `box`。模板读取 `element_size` 并赋给每个元素的 `size`。虽然 `shape` 可配置，但模板不读取 `parameters`，因此推荐使用 `shape = box`。如果需要圆柱阵列或球阵列，建议使用 `hierarchical` 或后续脚本生成通用 `[volume.*]` 配置。

### 9.2 必需配置

```ini
[world]
size = 20 cm, 20 cm, 20 cm
material = G4_AIR

[array]
material = G4_Si
element_size = 1 mm, 1 mm, 100 um
counts = 4, 4, 1
pitch = 1.2 mm, 1.2 mm, 100 um
```

### 9.3 完整示例

```ini
[world]
size = 20 cm, 20 cm, 20 cm
material = G4_AIR

[array]
name = PixelArray
shape = box
material = G4_Si
element_size = 1 mm, 1 mm, 100 um
counts = 4, 4, 1
pitch = 1.2 mm, 1.2 mm, 100 um
center = 0 mm, 0 mm, 0 mm
sensitive = true
bias = false
region = PixelRegion
```

### 9.4 array 支持的 key

| key | 含义 | 默认值 |
|---|---|---|
| `name` | 阵列元素名前缀 | `PixelArray` |
| `shape` | 元素形状，推荐 `box` | `box` |
| `material` | 元素材料 | 必需 |
| `element_size` | 单个元素完整尺寸 | 必需 |
| `counts` | x/y/z 方向数量，必须为正整数 | 必需 |
| `pitch` | x/y/z 方向间距，必须不小于对应元素尺寸 | 必需 |
| `center` | 阵列中心 | `0 mm, 0 mm, 0 mm` |
| `sensitive` | 元素是否 sensitive | `true` |
| `bias` | 元素是否 bias volume | `false` |
| `region` | 元素 region | 空 |

## 10. shielding 模板

示例文件：

```text
config/geometry/shielding.ini
```

### 10.1 实际生成形状

`shielding` 会生成：

1. 一个名为 `world` 的 `box`。
2. 若干沿 z 方向排列的屏蔽层，每层都是 `box`。
3. 一个可选的 `Detector`，也是 `box`。

当前只支持：

```ini
axis = z
```

每个屏蔽层尺寸为：

```text
x = area 第一个长度
y = area 第二个长度
z = thickness
```

位置从 `start` 开始，依次加上 `thickness + gap`。

### 10.2 完整示例

```ini
[world]
size = 1 m, 1 m, 1 m
material = G4_AIR

[shielding]
axis = z
area = 10 cm, 10 cm
start = -10 cm
gap = 0 mm
layers = Lead, Polyethylene

[shield.Lead]
thickness = 5 cm
material = G4_Pb
bias = true
region = LeadRegion

[shield.Polyethylene]
thickness = 10 cm
material = G4_POLYETHYLENE
bias = false
region = PolyRegion

[detector]
size = 10 cm, 10 cm, 1 cm
material = G4_Si
position = 0 mm, 0 mm, 20 cm
sensitive = true
region = DetectorRegion
```

### 10.3 shielding 支持的 key

`[shielding]`：

| key | 含义 | 默认值 |
|---|---|---|
| `axis` | 排列轴 | `z`，当前只支持 z |
| `area` | 每层 x/y 完整尺寸 | 必需 |
| `start` | 第一层 z 方向起始边界 | 必需 |
| `gap` | 层间间隔 | `0` |
| `layers` | 屏蔽层名称列表 | 必需 |

`[shield.Name]`：

| key | 含义 | 默认值 |
|---|---|---|
| `thickness` | 层厚度 | 必需 |
| `material` | 材料 | 必需 |
| `bias` | 是否 bias volume | `false` |
| `sensitive` | 是否 sensitive | `false` |
| `region` | region 名 | 空 |

`[detector]` 可选：

| key | 含义 | 默认值 |
|---|---|---|
| `size` | detector 完整尺寸 | section 存在时必需 |
| `material` | detector 材料 | section 存在时必需 |
| `position` | detector 位置 | section 存在时必需 |
| `sensitive` | 是否 sensitive | `true` |
| `region` | region 名 | 空 |

## 11. gdml 模板

示例文件：

```text
config/geometry/gdml_import.ini
```

### 11.1 当前状态

`gdml` 模板当前只是占位解析，不会真正导入 GDML 文件。

`GDMLTemplate` 会创建一个带有 `gdml_file` 属性的 placeholder world；但 `VolumeBuilder::CreateSolid()` 遇到 `gdml_file` 或 `gdml_placeholder` 会直接抛出：

```text
GDML geometry import is not implemented in VolumeBuilder yet
```

因此：当前不能用 `gdml` 模板完成真实运行初始化。

### 11.2 当前支持的配置 key

```ini
[gdml]
file = geometry/model.gdml
world_name = world
sensitive_volumes = SV1, SV2
bias_volumes = Shield1
region.SV1 = SensitiveRegion
region.Shield1 = ShieldRegion
```

其中：

| key | 含义 | 当前效果 |
|---|---|---|
| `file` | GDML 文件路径 | 必需，但不会真正导入 |
| `world_name` | placeholder world 名 | 可选 |
| `sensitive_volumes` | 预留 sensitive volume 列表 | 仅保存属性 |
| `bias_volumes` | 预留 bias volume 列表 | 仅保存属性 |
| `region.*` | 预留 region 映射 | 当前未接入构建 |

## 12. 动态添加体积命令

几何加载后，可以用 `/AIHL/geometry/...` 命令动态添加用户体积。命令只修改 `VolumeNode` 树，不直接创建 Geant4 对象。

修改后如果 run manager 已初始化，需要执行：

```tcl
/run/reinitializeGeometry
```

### 12.1 添加 box

```tcl
/AIHL/geometry/addBox name=ExtraDetector parent=world material=G4_Si size="1 cm,1 cm,1 mm" position="0 mm,0 mm,2 cm" rotation="0 deg,0 deg,0 deg" sensitive=true bias=false region=ExtraRegion
```

支持 key：

| key | 含义 | 是否必需 | 默认值 |
|---|---|---|---|
| `name` | 新体积名 | 必需 | 无 |
| `parent` | 母体积名 | 必需 | 无 |
| `material` | 材料名 | 必需 | 无 |
| `size` | box 完整尺寸 | 必需 | 无 |
| `position` | 位置 | 可选 | `0 mm,0 mm,0 mm` |
| `rotation` | 旋转 | 可选 | `0 deg,0 deg,0 deg` |
| `sensitive` | 是否 sensitive | 可选 | `false` |
| `bias` | 是否 bias volume | 可选 | `false` |
| `region` | region 名 | 可选 | 空 |
| `color` | 可视化颜色 | 可选 | 默认 |
| `alpha` | 透明度 | 可选 | 默认 |
| `visible` | 是否可见 | 可选 | 默认 |
| `wireframe` | 是否线框 | 可选 | 默认 |

### 12.2 添加 tubs / cylinder

```tcl
/AIHL/geometry/addTubs name=WaterCylinder parent=world material=G4_WATER rMin="0 mm" rMax="5 mm" halfZ="10 mm" startPhi="0 deg" deltaPhi="360 deg" position="0 mm,0 mm,-2 cm" sensitive=false bias=false
```

支持 key：

| key | 含义 | 是否必需 | 默认值 |
|---|---|---|---|
| `name` | 新体积名 | 必需 | 无 |
| `parent` | 母体积名 | 必需 | 无 |
| `material` | 材料名 | 必需 | 无 |
| `rMin` | 内半径 | 可选 | `0 mm` |
| `rMax` | 外半径 | 必需 | 无 |
| `halfZ` | 半高 | 必需 | 无 |
| `startPhi` | 起始方位角 | 可选 | `0 deg` |
| `deltaPhi` | 方位角跨度 | 可选 | `360 deg` |
| `position` | 位置 | 可选 | `0 mm,0 mm,0 mm` |
| `rotation` | 旋转 | 可选 | `0 deg,0 deg,0 deg` |
| `sensitive` | 是否 sensitive | 可选 | `false` |
| `bias` | 是否 bias volume | 可选 | `false` |
| `region` | region 名 | 可选 | 空 |

`GeometryMessenger` 的 key 查找是大小写不敏感的，所以 `rMin` 和 `rmin` 都能被识别。

### 12.3 通用 addVolume

当前 `/AIHL/geometry/addVolume` 只支持 `shape=box` 和 `shape=tubs`。

box：

```tcl
/AIHL/geometry/addVolume name=Box2 parent=world shape=box material=G4_Si size="1 mm,1 mm,1 mm"
```

tubs：

```tcl
/AIHL/geometry/addVolume name=Cyl2 parent=world shape=tubs material=G4_WATER parameters="0 mm,5 mm,10 mm,0 deg,360 deg"
```

注意：虽然通用 ini 的 `hierarchical` 可以表达 `sphere/orb/cone`，当前动态 `addVolume` 命令只开放了 `box/tubs`。

### 12.4 删除和列出用户添加体积

```tcl
/AIHL/geometry/listUserVolumes
/AIHL/geometry/removeUserVolume ExtraDetector
/AIHL/geometry/clearUserVolumes
```

### 12.5 重新加载配置时是否保留用户添加体积

```tcl
/AIHL/geometry/preserveUserVolumesOnLoad true
```

默认行为是保留用户添加体积，并在下一次 `loadConfig` 后重新挂接。

## 14. 各模板如何设置探测器

在当前框架中，“探测器”不是一个单独的几何类型，而是普通 `VolumeNode` 的一个标志：

```ini
sensitive = true
```

当 `VolumeBuilder` 构建几何时，如果某个体积设置了 `sensitive = true`，会执行：

1. 创建该体积的 `G4LogicalVolume`；
2. 调用 `GeometryRegistry::MarkSensitiveVolume(volumeName)` 记录它；
3. `DetectorConstruction::ConstructSDandField()` 从 `GeometryRegistry` 获取 sensitive logical volumes；
4. 如果已经通过 `DetectorConstruction::SetSensitiveDetectorFactory(...)` 设置了 SD factory，则给这些 logical volume 绑定 `SensitiveDetector`；
5. 运行时 `SensitiveDetector::ProcessHits()` 会把 step 转为 `ParticleHit`，再转为 `HitRecord`，交给 `ScoringManager::ScoreHit()`。

因此，几何配置中设置探测器的核心就是：选择一个或多个体积，并给它们写 `sensitive = true`。如果还希望这些体积有独立 region 或 production cuts，再配合写 `region` 和 `cut.*`。

### 14.1 simple_box 中设置探测器

`simple_box` 模板只有一个 target 子体积。这个 target 就是最常用的探测器体积。

```ini
[target]
name = Target
shape = box
size = 1 cm, 1 cm, 1 mm
material = G4_Si
position = 0 mm, 0 mm, 0 mm
sensitive = true
region = SV
cut.e- = 1 um
```

实现细节：

- world 永远不是探测器；
- `[target] sensitive` 默认值是 `true`；
- 如果不写 `sensitive`，`Target` 仍会被注册为 sensitive volume；
- `region = SV` 不是成为探测器的必要条件，但推荐给探测器设置 region，便于 cuts、MicroElec、biasing 或后续 scoring 扩展定位。

如果想让 `simple_box` 只作为普通靶材、不输出 hit，可以写：

```ini
[target]
sensitive = false
```

### 14.2 layered_device 中设置探测器

`layered_device` 的每一层都可以单独设置是否为探测器。

```ini
[layers]
count = 3
names = Substrate, Oxide, Metal

[layer.Substrate]
thickness = 500 um
xy = 10 mm, 10 mm
material = G4_Si
sensitive = false

[layer.Oxide]
thickness = 1 um
xy = 10 mm, 10 mm
material = G4_WATER
sensitive = true
region = OxideRegion

[layer.Metal]
thickness = 2 um
xy = 10 mm, 10 mm
material = G4_Cu
sensitive = true
bias = true
region = MetalRegion
```

实现细节：

- 每个 `[layer.Name]` 都生成一个 `box`；
- `[layer.Name] sensitive` 默认值是 `false`；
- 只有显式写 `sensitive = true` 的层会成为探测器；
- 多个 layer 可以同时设置为 sensitive，它们会共享当前 `DetectorConstruction` 绑定的同一个 SD 实例；
- `bias = true` 可以和 `sensitive = true` 同时存在，表示同一层既计分又作为 bias volume。

推荐用法：

- 半导体敏感层：`sensitive = true`；
- 纯支撑层或封装层：`sensitive = false`；
- 需要低 cut 的敏感层：同时写 `region` 和 `cut.e- / cut.gamma` 等。

### 14.3 hierarchical 中设置探测器

`hierarchical` 是最灵活的方式。任何 `[volume.*]` 子体积都可以设置为探测器。

```ini
[world]
shape = box
size = 10 cm, 10 cm, 10 cm
material = G4_AIR

[volume.Container]
parent = world
shape = box
size = 5 cm, 5 cm, 5 cm
material = G4_WATER

[volume.SiliconSensor]
parent = Container
shape = box
size = 1 cm, 1 cm, 300 um
material = G4_Si
position = 0 mm, 0 mm, 0 mm
sensitive = true
region = SensorRegion
cut.e- = 100 nm
```

实现细节：

- `[world]` 不应该作为探测器使用；
- 所有 `[volume.*]` 默认 `sensitive = false`；
- 只要某个体积写 `sensitive = true`，它就会被 `GeometryRegistry` 记录；
- 可以把 `box/tubs/sphere/orb/cone` 任意一种可构建形状设置为 sensitive；
- 如果一个母体积和子体积都设置 `sensitive = true`，两者都会绑定 SD，可能导致同一粒子经过嵌套体积时产生你不期望的重复或重叠记录，建议谨慎使用。

圆柱探测器示例：

```ini
[volume.CylindricalDetector]
parent = world
shape = tubs
parameters = 0 mm, 5 mm, 10 mm, 0 deg, 360 deg
material = G4_Si
position = 0 mm, 0 mm, 0 mm
sensitive = true
region = CylDetectorRegion
```

球形探测器示例：

```ini
[volume.SphericalDetector]
parent = world
shape = sphere
parameters = 0 mm, 5 mm, 0 deg, 360 deg, 0 deg, 180 deg
material = G4_WATER
sensitive = true
region = SphereDetectorRegion
```

### 14.4 array 中设置探测器

`array` 模板会生成规则阵列，每个阵列元素都使用同一组 detector 设置。

```ini
[array]
name = PixelArray
shape = box
material = G4_Si
element_size = 1 mm, 1 mm, 100 um
counts = 4, 4, 1
pitch = 1.2 mm, 1.2 mm, 100 um
sensitive = true
region = PixelRegion
```

实现细节：

- 每个像素元素都会生成一个独立体积，例如 `PixelArray_0_0_0`；
- `[array] sensitive` 默认值是 `true`；
- 如果 `sensitive = true`，所有阵列元素都会成为探测器；
- 当前模板不能按单个像素分别设置 sensitive；若需要只有部分像素敏感，建议使用 `hierarchical` 显式列出体积，或后续用脚本生成 `[volume.*]` 配置；
- 所有像素使用同一个 `region` 名称时，它们都会被加入同名 Geant4 region。

如果只是想构建非敏感结构阵列：

```ini
[array]
sensitive = false
```

### 14.5 shielding 中设置探测器

`shielding` 模板有两类可能成为探测器的体积：

1. 屏蔽层 `[shield.Name]`；
2. 可选后方探测器 `[detector]`。

屏蔽层作为探测器：

```ini
[shield.Lead]
thickness = 5 cm
material = G4_Pb
sensitive = true
region = LeadScoringRegion
```

后方 detector：

```ini
[detector]
size = 10 cm, 10 cm, 1 cm
material = G4_Si
position = 0 mm, 0 mm, 20 cm
sensitive = true
region = DetectorRegion
```

实现细节：

- `[shield.Name] sensitive` 默认值是 `false`；
- `[detector] sensitive` 默认值是 `true`；
- 如果存在 `[detector]` section，模板会创建一个名为 `Detector` 的 box；
- `[detector]` 适合做屏蔽后方的计数/能量沉积探测器；
- 如果想统计某个屏蔽层内部沉积，也可以给该 `[shield.Name]` 写 `sensitive = true`。

### 14.6 gdml 中设置探测器

`gdml` 模板当前尚未真正导入 GDML，因此不能完成真实探测器绑定。

配置中可以写：

```ini
[gdml]
file = geometry/model.gdml
world_name = world
sensitive_volumes = SV1, SV2
bias_volumes = Shield1
```

但当前效果只是把这些值保存到 placeholder 的属性中。`VolumeBuilder` 仍会因为 GDML 导入未实现而报错，所以这些 `sensitive_volumes` 目前不会真正进入 `GeometryRegistry`。

结论：当前不要依赖 `gdml` 模板设置探测器。

### 14.7 动态添加探测器

通过 `/AIHL/geometry/addBox` 或 `/AIHL/geometry/addTubs` 动态添加体积时，也可以直接设置为探测器：

```tcl
/AIHL/geometry/addBox name=ExtraDetector parent=world material=G4_Si size="1 cm,1 cm,1 mm" position="0 mm,0 mm,2 cm" sensitive=true region=ExtraRegion
/run/reinitializeGeometry
```

圆柱探测器：

```tcl
/AIHL/geometry/addTubs name=WaterDetector parent=world material=G4_WATER rMin="0 mm" rMax="5 mm" halfZ="10 mm" sensitive=true region=WaterDetectorRegion
/run/reinitializeGeometry
```

注意：

- 动态添加命令成功后只修改 `VolumeNode` 树；
- 如果 run manager 已初始化，必须执行 `/run/reinitializeGeometry`；
- 新体积的 `parent` 必须已经存在；
- 新体积名不能与当前树中已有体积重复。

### 14.8 探测器设置与输出文件的关系

设置 `sensitive = true` 只是几何侧登记探测器体积。要真正输出 hit 和 edep，还需要：

1. `DetectorConstruction` 已设置 SD factory；
2. Scoring 已开启；
3. Source 粒子能打到 sensitive volume；
4. `/run/initialize` 成功完成。

最小 scoring 命令示例：

```tcl
/AIHL/scoring/enable true
/AIHL/scoring/hits true
/AIHL/scoring/eventEdep true
/AIHL/scoring/edep true
```

成功运行后通常会看到：

```text
hits_t0.csv
event_edep_t0.csv
hist_edep_raw_t0.csv
hist_edep_weighted_t0.csv
```

如果没有 `hits_t0.csv` 或文件为空，优先检查：

- 目标体积是否真的写了 `sensitive = true`；
- `/AIHL/geometry/printTree` 中是否能看到该体积；
- 粒子源方向和位置是否能打到探测器；
- `/AIHL/detector/enableSD false` 是否被调用过；
- Scoring 的 hit 输出是否开启。

## 15. 推荐选择哪个模板

| 需求 | 推荐模板 |
|---|---|
| 最小验证、单个探测器块 | `simple_box` |
| 半导体/靶材分层结构 | `layered_device` |
| 多级父子体积、圆柱、球、锥等混合形状 | `hierarchical` |
| 像素阵列、规则 box 阵列 | `array` |
| 屏蔽层 + 后方 detector | `shielding` |
| GDML 文件 | 当前不推荐，尚未真正实现导入 |

如果不确定，优先使用 `hierarchical`。它最接近底层 `VolumeNode` 能力，后续扩展和排错也最直接。

## 16. 常见错误

### 16.1 `root node is not set`

说明几何配置没有成功加载。常见原因：

- 没有执行 `/AIHL/geometry/loadConfig`；
- 模板名不正确；
- ini 缺少必需 key；
- 配置文件路径错误。

检查：

```tcl
/AIHL/geometry/print
/AIHL/geometry/printTree
```

### 16.2 `missing [world]/size`

说明当前模板要求 `[world] size`，但配置文件没有写。例如 `simple_box/layered_device/array/shielding` 都需要：

```ini
[world]
size = 10 cm, 10 cm, 10 cm
material = G4_AIR
```

### 16.3 `Unsupported shape`

说明 shape 名称不能被构建。当前可构建的是：

```text
box, tubs, sphere, orb, cone
```

不要使用 `trapezoid`，它当前只被解析器识别，构建器未实现。

### 16.4 `requires 5 tubs parameters`

说明 `shape=tubs` 缺少参数。应写：

```ini
parameters = 0 mm, 5 mm, 10 mm, 0 deg, 360 deg
```

### 16.5 `Material not found`

说明体积使用的材料没有被 `MaterialManager` 加载或 NIST 无法构建。

请先执行：

```tcl
/AIHL/material/load config/materials/material.ini
/AIHL/material/print
```

并确认几何中的 `material = ...` 名称存在。

### 16.6 修改几何后 beamOn 没变化

动态添加、删除体积后，已经初始化过的 run manager 不会自动重建几何。需要：

```tcl
/run/reinitializeGeometry
```


## 18. 当前几何模块限制

1. `gdml` 模板尚未真正导入 GDML，不能用于完整初始化。
2. `trapezoid` 形状未在 `VolumeBuilder` 中实现。
3. `placement = replica/parameterised/assembly` 目前会被解析，但构建阶段仍使用普通 `G4PVPlacement`。
4. `simple_box`、`array` 的 `shape` 字段虽然存在，但模板没有读取形状专用 `parameters`；复杂形状请使用 `hierarchical`。
5. `layered_device` 和 `shielding` 当前只支持沿 z 方向排列。
6. 动态 `/AIHL/geometry/addVolume` 当前只支持 `box` 和 `tubs`。
