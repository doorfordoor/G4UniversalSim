# G4UniversalSim 中文几何配置说明

整理日期：2026-07-03。本文件只说明当前后端代码真正读取和构建的几何配置。命令行和非几何模块见 `docs/中文使用手册.md`。

## 1. 几何入口

主配置通过 `[geometry]` 指向几何模板和几何文件：

```ini
[geometry]
template = hierarchical
config = config/geometry/hierarchical_volume.ini
check_overlaps = true
default_world_material = G4_AIR
```

模板名由 `TemplateFactory` 解析：

| 模板 | 别名 | 当前状态 |
| --- | --- | --- |
| `simple_box` | `simple` | 可运行，生成一个 world 和一个 target。 |
| `layered_device` | `layered` | 可运行，沿 z 轴自动堆叠盒状层。 |
| `hierarchical` | 无 | 可运行，读取 `[world]` 和 `[volume.*]` 层级体积。 |
| `array` | 无 | 可运行，生成规则盒状阵列。 |
| `shielding` | 无 | 可运行，生成屏蔽层和可选 detector。 |
| `gdml` | 无 | 只是占位，后端尚未实现真实 GDML 导入。 |

## 2. 单位和向量

长度向量常见写法：

```ini
size = 10 cm, 10 cm, 10 cm
position = 0 mm, 0 mm, -1 mm
rotation = 0 deg, 0 deg, 0 deg
```

长度字段支持 `nm`、`um`、`mm`、`cm`、`m`。角度字段支持 `deg` 和 `rad`。`parameters` 使用 Geant4 单位表解析，长度和角度可以混写，例如 `0 mm, 5 mm, 10 mm, 0 deg, 360 deg`。

`box` 的 `size` 表示完整尺寸，后端创建 `G4Box` 时会自动转为半长。`G4Tubs`、`G4Sphere`、`G4Cons`、`G4Trd`、`G4Trap` 的参数按 Geant4 构造函数习惯，多数是半长。

## 3. 通用层级体积格式

`hierarchical` 模板使用一个 `[world]` 段和多个 `[volume.<name>]` 段：

```ini
[world]
shape = box
size = 10 cm, 10 cm, 10 cm
material = G4_AIR

[volume.Detector]
parent = world
shape = box
size = 1 cm, 1 cm, 1 mm
material = G4_Si
position = 0 mm, 0 mm, 0 mm
rotation = 0 deg, 0 deg, 0 deg
sensitive = true
bias = false
region = SV
copyNo = 1
cut.e- = 100 nm
vis.color = blue
vis.alpha = 0.6
```

通用字段：

| 字段 | 说明 |
| --- | --- |
| `parent` | 非 world 体积必填，必须引用已存在体积名。 |
| `shape` | 支持 `box`、`tubs`、`sphere`、`orb`、`cone`、`trd`、`trap`。 |
| `material` | 必填，引用已加载材料或 NIST 材料。 |
| `size` | 主要用于 `box`。`simple_box` 里也会传给 target。 |
| `parameters` | `tubs`、`sphere`、`orb`、`cone` 常用。 |
| `position` | 相对母体积的位置，缺省为原点。 |
| `rotation` | 绕 x/y/z 的旋转角，缺省为 0。 |
| `sensitive` | 为 `true` 时注册敏感逻辑体，可产生 hit。 |
| `bias` | 为 `true` 时作为 biasing 默认候选体积。 |
| `region` | 给逻辑体创建或加入 Geant4 region。 |
| `copyNo` | 写入 `G4PVPlacement` copy number。 |
| `cut.gamma`、`cut.e-`、`cut.e+`、`cut.proton` | 配合 `region` 设置 production cut。 |
| `vis.color`、`vis.alpha`、`vis.visible`、`vis.wireframe` | 设置可视化属性。 |

未知字段会保存在 `VolumeNode::userProperties` 中。`trd` 和 `trap` 的形状参数就是通过这些属性传给 `VolumeBuilder`。

## 4. 当前可构建形状

### box

```ini
[volume.Box]
parent = world
shape = box
size = 10 mm, 5 mm, 1 mm
material = G4_Si
```

### tubs / tube / cylinder

```ini
[volume.Cylinder]
parent = world
shape = tubs
parameters = 0 mm, 5 mm, 10 mm, 0 deg, 360 deg
material = G4_WATER
```

参数顺序为 `rMin, rMax, halfZ, startPhi, deltaPhi`。

### sphere

```ini
[volume.Sphere]
parent = world
shape = sphere
parameters = 0 mm, 5 mm, 0 deg, 360 deg, 0 deg, 180 deg
material = G4_WATER
```

参数顺序为 `rMin, rMax, startPhi, deltaPhi, startTheta, deltaTheta`。

### orb

```ini
[volume.Orb]
parent = world
shape = orb
parameters = 5 mm
material = G4_WATER
```

在 `hierarchical` 配置中建议使用 `parameters = radius`。`VolumeBuilder` 虽有 `size.x` 简写逻辑，但通用 INI 解析器不会为 `orb` 解析 `size`。

### cone / cons

```ini
[volume.Cone]
parent = world
shape = cone
parameters = 0 mm, 5 mm, 0 mm, 2 mm, 10 mm, 0 deg, 360 deg
material = G4_Si
```

参数顺序为 `rMin1, rMax1, rMin2, rMax2, halfZ, startPhi, deltaPhi`。

### trd / trapezoid

```ini
[volume.Trd]
parent = world
shape = trd
material = G4_Si
dx1 = 5 mm
dx2 = 2 mm
dy1 = 4 mm
dy2 = 4 mm
dz = 1 mm
```

参数均为半长，对应 `G4Trd(dx1, dx2, dy1, dy2, dz)`。

### trap

```ini
[volume.Trap]
parent = world
shape = trap
material = G4_Si
dz = 1 mm
theta = 0 deg
phi = 0 deg
dy1 = 4 mm
dx1 = 5 mm
dx2 = 2 mm
alpha1 = 0 deg
dy2 = 4 mm
dx3 = 5 mm
dx4 = 2 mm
alpha2 = 0 deg
```

参数对应完整 `G4Trap` 构造函数。长度参数必须大于 0。

### 路线图 A5 新增形状（实验性）

以下形状用于 hierarchical 普通体积（`[world]` 和 `[volume.<名称>]`），不能作为布尔工具（作为工具时在创建几何对象前报错）。长度、角度都要带单位。验证见 `scripts/test_geometry_a5.py`：Geant4 计算的体积与解析公式相差 ≤ 1e-12，质量等于密度乘体积。

| `shape` | 字段 | 对应 Geant4 solid |
| --- | --- | --- |
| `ellipsoid` | `parameters = ax, by, cz` 或 `ax, by, cz, zBottomCut, zTopCut`（半轴；切割平面可选） | `G4Ellipsoid` |
| `eltube` | `parameters = dx, dy, dz`（半长） | `G4EllipticalTube` |
| `torus` | `parameters = rMin, rMax, rTor, startPhi, deltaPhi`，要求 0 ≤ rMin < rMax ≤ rTor | `G4Torus` |
| `para` | `parameters = dx, dy, dz, alpha, theta, phi`（半长与三个倾角） | `G4Para` |
| `hype` | `parameters = innerRadius, outerRadius, innerStereo, outerStereo, halfZ` | `G4Hype` |
| `polycone` | `parameters = startPhi, deltaPhi`；`z_planes`、`r_inner`、`r_outer` 为等长列表（≥ 2 个平面，z 不递减，0 ≤ r_inner ≤ r_outer） | `G4Polycone` |
| `polyhedra` | `parameters = startPhi, deltaPhi, numSide`；平面列表同上，半径为到侧面的距离 | `G4Polyhedra` |
| `tessellated`（别名 `stl`） | `file = 网格.stl`（相对路径按几何文件所在目录解析），可选 `file_unit = mm`（默认）/`cm`/`m` | `G4TessellatedSolid` |

```ini
[volume.Lens]
parent = world
shape = polycone
parameters = 0 deg, 360 deg
z_planes = -20 mm, 0 mm, 20 mm
r_inner = 0 mm, 5 mm, 0 mm
r_outer = 10 mm, 20 mm, 10 mm
material = G4_PLEXIGLASS
```

**STL/CAD 导入**：支持 ASCII 与二进制 STL。读取时合并重合顶点，要求网格封闭且为一致定向的流形（每条边恰好被两个三角形以相反方向使用），否则在创建几何对象前报错并给出开放边；整体朝内（体积为负）的网格会自动翻转。实测 STL 立方体中 2000 个各向同性 geantino 全部从表面准确离开（偏差 0），弦长之和与注量径迹长度一致。限制：只支持三角形 STL（没有 STEP/IGES，可先用 CAD 软件导出 STL）；大网格会使导航变慢；STL 可经 GDML 导出/导入（见第 10 节）。

### 路线图 A5 副本放置（实验性）

`placement` 现支持 `normal`（默认）、`replica`、`parameterised`；`assembly` 仍在创建几何对象前拒绝。Geant4 要求 replica 和 parameterised 体积是其母体的**唯一**子体积，违反时同样在创建前报错。

**replica**（`G4PVReplica`）把母体等分切片：

| 字段 | 说明 |
| --- | --- |
| `replica_axis` | `x`、`y`、`z`（母体和切片都是 box）或 `phi`（母体和切片都是 tubs）。 |
| `replica_count` | 切片数。 |
| `replica_width` | 切片宽度（长度；`phi` 时为角度），`count × width` 必须等于母体沿该轴的全长或 `deltaPhi`。 |
| `replica_offset` | 仅 `phi` 可用，默认等于母体的 `startPhi`，显式给出时也必须等于它。 |

切片形状必须与母体一致：box 切片除该轴为 `replica_width` 外与母体同尺寸；phi 切片的半径、halfZ 与母体相同，`deltaPhi = replica_width`，且 `startPhi = -replica_width/2`（以 φ = 0 为中心，Geant4 再把第 i 片转到 [offset + i·w, offset + (i+1)·w]）。切片不能写 `position`、`rotation`、`copyNo`，copy number 依次为 0…N−1，剂量/注量按 touchable（例如 `/world_PV#0/Stack_PV#0/Slice_PV#3`）分别统计。

```ini
[volume.Stack]
parent = world
shape = box
size = 50 mm, 50 mm, 100 mm
material = G4_WATER

[volume.Slice]
parent = Stack
shape = box
size = 50 mm, 50 mm, 10 mm
material = G4_WATER
placement = replica
replica_axis = z
replica_count = 10
replica_width = 10 mm
sensitive = true
```

实测：100 MeV 质子在 10 片 z 向 replica 中的逐片剂量与 10 个独立放置的平板一致（|pull| < 5，A3 统计误差），每片质量 25 g；位于 phi 第 1 扇区内的束流只计入 copy 1。

**parameterised**（`G4PVParameterised`）放置同一形状的多个副本，二选一：

- `copies_file = 副本.csv`：表头 `x_mm,y_mm,z_mm`，可加 `rot_x_deg,rot_y_deg,rot_z_deg`，可在最后加 `material`（为空时使用体积自身的 `material`），`#` 为注释，相对路径按几何文件目录解析；此时不能写 `position`、`rotation`。
- `copies = N` + `copy_step = dx, dy, dz`：从 `position` 开始按步长排列，每个副本使用体积自身的 `rotation`。

逐副本材料会进入剂量质量（实测水/Si/Pb 三个 1 cm³ 副本质量为 1.00/2.33/11.35 g）。overlap 检查对每个副本执行。

### 路线图 A5 后端几何导出（真实预览）

初始化后执行 `/AIHL/geometry/exportMesh <文件.json>`（只读，仅 `Idle` 状态可用）会把 Geant4 实际构建的世界写成 `g4usim_geometry_mesh_v1` JSON：每个物理体积副本（包括每个 replica、parameterised 副本）一条记录，含 touchable 路径、copy number、solid 类型、材料（parameterised 为逐副本材料）、是否敏感、Geant4 体积以及世界坐标下的多边形网格（mm，面为 0 基索引的三角形或四边形）。网格来自 Geant4 的 `G4Polyhedron`，布尔实体和 STL 都按真实结果导出；曲面为多边形近似。GUI 3D 预览页的“显示后端几何”按钮即调用该命令（仅 `/run/initialize`，不运行事件）并显示结果。

## 5. 布尔实体操作

布尔操作写在目标体积下：

```ini
[volume.Target]
parent = world
shape = box
size = 14 mm, 12 mm, 8 mm
material = G4_Si
sensitive = true
region = SV

[volume.Target.boolean.0]
operation = subtraction
shape = tubs
parameters = 0 mm, 1.5 mm, 5 mm, 0 deg, 360 deg
position = -3 mm, 0 mm, 0 mm
rotation = 0 deg, 0 deg, 0 deg
name = left_hole

[volume.Target.boolean.1]
operation = union
shape = box
size = 6 mm, 8 mm, 6 mm
position = 7 mm, 0 mm, 0 mm
name = side_extension
```

规则：

- section 名必须是 `[volume.<目标体积>.boolean.<序号>]`。
- 序号必须从 0 开始连续。
- `operation` 支持 `subtraction`、`union`、`intersection`，也兼容 `subtract`、`cut`、`minus`、`add`、`intersect`。
- 布尔工具是 solid operand，不是普通体积，不设置 `material`、`sensitive`、`bias`、`region`、`parent`、`copyNo` 或 `cut.*`。
- 操作按序号顺序串行执行，含义类似 `(((base op0 tool0) op1 tool1) op2 tool2)`。
- union 和 intersection 能运行，但几何解释更复杂，建议开启 overlap 检查并做可视化确认。
- 布尔工具边界不要刚好与母实体共面，轻微穿透更稳。

## 6. simple_box 模板

`simple_box` 适合一个 world 加一个 target 的最小模型：

```ini
[world]
size = 10 cm, 10 cm, 10 cm
material = G4_AIR

[target]
name = Target
shape = box
size = 1 cm, 1 cm, 1 mm
material = G4_Si
position = 0 mm, 0 mm, 0 mm
rotation = 0 deg, 0 deg, 0 deg
sensitive = true
bias = false
region = SV
cut.gamma = 1 um
cut.e- = 1 um
cut.e+ = 1 um
cut.proton = 1 um

[visual.world]
color = white
alpha = 0.05
visible = true
wireframe = true

[visual.target]
color = blue
alpha = 0.6
visible = true
wireframe = false
```

必填字段是 `[world]/size`、`[world]/material`、`[target]/size` 和 `[target]/material`。

## 7. layered_device 模板

`layered_device` 沿 z 轴自动堆叠盒状层：

```ini
[world]
size = 20 cm, 20 cm, 20 cm
material = G4_AIR

[layers]
count = 3
names = Substrate, Oxide, Metal
auto_stack = true
axis = z
gap = 0 um

[layer.Substrate]
thickness = 500 um
xy = 10 mm, 10 mm
material = G4_Si
sensitive = false
bias = false
region = SubstrateRegion

[layer.Oxide]
thickness = 1 um
xy = 10 mm, 10 mm
material = G4_WATER
sensitive = true
region = OxideRegion
cut.e- = 100 nm
```

规则：

- `[layers]/axis` 当前只支持 `z`。
- `[layers]/count` 必须与 `names` 数量一致。
- 每个 `[layer.<name>]` 必须有 `thickness`、`xy` 和 `material`。
- `auto_stack = true` 时自动计算 z 位置。若关闭，则每层必须写 `position`。
- 层支持 `copyNo`，未知层字段会保存在 `userProperties`。

## 8. array 模板

`array` 生成规则三维阵列，当前元素主要按盒状尺寸使用：

```ini
[world]
size = 10 cm, 10 cm, 10 cm
material = G4_AIR

[array]
name = Pixel
counts = 4,4,1
element_size = 1 mm, 1 mm, 0.3 mm
pitch = 1.2 mm, 1.2 mm, 1 mm
center = 0 mm, 0 mm, 0 mm
shape = box
material = G4_Si
sensitive = true
bias = false
region = PixelRegion
```

`pitch` 必须不小于 `element_size` 的对应轴尺寸。

## 9. shielding 模板

`shielding` 沿 z 轴生成屏蔽层，可选 detector：

```ini
[world]
size = 50 cm, 50 cm, 50 cm
material = G4_AIR

[shielding]
axis = z
area = 20 cm, 20 cm
start = -10 cm
gap = 0 cm
layers = Lead, Copper

[shield.Lead]
thickness = 1 cm
material = G4_Pb
bias = true

[shield.Copper]
thickness = 5 mm
material = G4_Cu

[detector]
size = 1 cm, 1 cm, 1 mm
position = 0 mm, 0 mm, 5 cm
material = G4_Si
sensitive = true
region = DetectorRegion
```

`axis` 当前只支持 `z`。

## 10. GDML 导入与导出（路线图 A5，实验性）

需要后端链接的 Geant4 启用 GDML（XercesC）。本机自 2026-10-22 起使用带 GDML 的 Geant4 11.3.2（见 `docs/测试平台说明.md` 的环境一节）；若后端构建时的 Geant4 没有 GDML，`--capabilities` 中 `gdml` 模板为 `runtime:false`，`[gdml]` 配置在创建几何对象前失败并说明原因。

**导入**：主 INI 写 `[geometry] template = gdml`，`config` 指向一个只含 `[gdml]` 节的几何 INI：

| 字段 | 说明 |
| --- | --- |
| `file` | GDML 文件，相对路径按该几何 INI 所在目录解析；不存在时在初始化前报错。 |
| `validate` | 默认 `false`；`true` 时按文件中的 schema 做 XML 校验（schema 地址通常是网络 URL，离线时可能失败）。 |
| `sensitive_volumes` | 逗号分隔的**逻辑体**名，标记为敏感体（hits、Dose、Fluence、LET 计分）；名称不存在时报错并列出文件中的全部逻辑体。 |
| `bias_volumes` | 同上，标记为 bias 体。 |

GDML 文件中的 `<auxiliary auxtype="SensDet" .../>` 也会把该逻辑体标记为敏感体。`[geometry] check_overlaps = true` 时读取过程中逐体检查重叠。材料取自 GDML 文件本身。

```ini
# geometry_gdml.ini
[gdml]
file = detector.gdml
sensitive_volumes = Det_LV, Shield_LV
```

**导出**：初始化后执行 `/AIHL/geometry/exportGDML <新文件.gdml>`（只读命令，仅 `Idle` 状态可用），把 Geant4 实际构建的世界写成 GDML，名称不带指针后缀；目标文件已存在时拒绝覆盖。

**往返验证**（`scripts/test_geometry_a5.py`）：含 polycone、STL、布尔、z 向 replica、parameterised、旋转体的几何导出后再导入，20 个体积副本的 solid、材料、世界坐标网格完全一致（顶点差 0），质量一致，逐片剂量在 5σ 内一致；手写 GDML 的 SensDet 标记生效。

**限制（GDML 格式本身）**：
- GDML 不保存 world、replica 和 parameterised 物理体的名称，Geant4 读回后分别命名为 `<逻辑体>_PV`（world、replica）和 `<逻辑体>_param`，因此 touchable 路径会变化（例如 `/world_PV#0/Stack_PV#0/Slice_PV#3` 读回为 `/world_LV_PV#0/Stack_PV#0/Slice_LV_PV#3`）。
- parameterised 的逐副本材料不会写入 GDML（GDML paramvol 只记录位置与尺寸）。
- 本项目的 `region`、production cut、可视化属性和 `bias` 标记不写入 GDML；导入时需在 `[gdml]` 中重新指定敏感体和 bias 体。

## 11. 动态几何命令

macro 中可用 `/AIHL/geometry/...` 动态增加用户体积：

```text
/AIHL/geometry/addBox name=Extra parent=world material=G4_Si size="1 cm,1 cm,1 mm" position="0 mm,0 mm,2 cm"
/AIHL/geometry/addTubs name=Tube parent=world material=G4_WATER rMax=5 mm halfZ=10 mm deltaPhi=360 deg
/AIHL/geometry/addVolume name=Extra2 parent=world material=G4_Si shape=box size="1 mm,1 mm,1 mm"
```

限制：

- `addVolume` 当前只支持 `box` 和 `tubs`。
- 初始化后修改几何树，需要 `/run/reinitializeGeometry` 或重启进程。
- `removeUserVolume` 只能删除用户动态添加的体积。

## 12. 敏感体、bias 体积和 region

`sensitive = true` 会把体积标记为敏感体，`DetectorConstruction` 构建后会给这些 logical volume 挂 `SensitiveDetector`。要产生 hit，还需要 `[scoring]/hits = true`，并且粒子确实在敏感体内有沉积。

`bias = true` 会把体积标记为 biasing 候选体积。当 process-level biasing 规则没有显式 `volumes` 时，`BiasingManager` 会尝试使用这些体积。

`region = <name>` 会创建或复用 Geant4 region。若同一体积还设置了 `cut.*`，后端会给该 region 设置 production cuts。

## 13. 可视化属性

可视化属性只影响 Geant4 可视化，不影响物理：

```ini
vis.color = blue
vis.alpha = 0.6
vis.visible = true
vis.wireframe = false
```

当前颜色名支持 `white`、`black`、`red`、`green`、`blue`、`yellow`、`cyan`、`magenta`、`gray`、`grey`。未知颜色会警告并使用灰色。

## 14. 常见错误

### 缺少 world

`hierarchical` 模板必须有 `[world]`。如果报 `Geometry config has no world volume`，先检查 section 名是否拼错。

### parent 不存在或形成环

每个非 world 体积的 `parent` 必须引用已定义体积，且不能形成循环。

### `Unsupported shape`

后端支持的 shape 是 `box`、`tubs`、`sphere`、`orb`、`cone`、`trd`、`trap`。GUI 编辑器的白名单可能比后端更窄，若 GUI 阻止生成，请使用手写配置或更新 GUI 校验逻辑。

### `requires 5 tubs parameters`

`tubs` 必须提供 5 个参数：`rMin,rMax,halfZ,startPhi,deltaPhi`。

### 布尔操作不生效或结果异常

确认布尔 section 目标体积存在，序号从 0 连续，工具实体参数正确。对于 subtraction，工具体积最好略微穿透目标体积，避免刚好共面。

### 修改几何后下一次运行仍是旧几何

初始化后修改几何，通常需要 `/run/reinitializeGeometry`。但当前工作区中 biasing operator 已挂接时该命令会被 batch runner 明确拒绝：此组合曾造成访问违例，应在新进程中重建。最稳妥做法是在 `/run/initialize` 前完成所有几何配置。

## 13. M0-3B2B1 安全校验边界

M0-3B2B1 已完成会影响运行安全的前置校验，但尚未把几何文件改成完整闭合 schema：

- production cut 只允许 `cut.gamma`、`cut.e-`、`cut.e+`、`cut.proton`，并且同一普通 volume section 必须有非空 `region`。`cut.electron` 等拼写会在任何 Geant4 geometry object 创建前失败。
- `simple_box` 的 target 与 `array` 的 element 只允许 `shape=box`；`layered_device` 和 `shielding` 继续固定为 box。
- hierarchical 的 `box/tubs/sphere/orb/cone/trd/trap` 以及 boolean tool 在构建前检查精确参数数量。`orb` 只接受一个 `parameters=radius`，不再接受不可达的 `size` 简写；`trd/trap` 使用各自完整的显式字段。
- `copyNo` 必须是 signed 32-bit integer；非 normal placement 继续走 M0-3A 专用拒绝并建议使用显式子 volume。
- 错误包含文件、行号、section、原始 key/value；安全失败会报告 `created_geometry_object_count=0`。

完整来源诊断和兼容 warning 已在 M0-3B2B2 补齐；B3 工作区新增显式 `version=2` 的后端严格模式，自动迁移和完整无损 round-trip 仍属于后续 B3 工作。

### M0-3B2B2 来源诊断与兼容 warning

当前几何文件会产生结构化 `[GeometryConfigWarning] file:line [section]/key = value: message; suggestion`。诊断包含 `unknown_section`、`unconsumed_key`、`legacy_metadata` 和 `ignored_boolean_key`，按来源稳定排序去重，并同时写入控制台和 `run_summary.txt`。主配置的 `config_warning_count` 与几何配置的 `geometry_config_warning_count` 分开统计。

`metadata.<非空名称>` 是只保存的 canonical metadata，不参与 Geant4 运行；hierarchical/layered 的旧式无前缀属性会保留并建议改为 `metadata.<原key>`，不会自动改名。无版本或 `[global] version = 1` 的文件仍采用兼容 warning；`[global] version = 2` 会把 `unknown_section`、`unconsumed_key`、`legacy_metadata`、`ignored_boolean_key` 在创建几何对象前升级为错误，错误带文件、行号及原始字段。无效或重复版本声明也会失败。该严格模式覆盖当前诊断类别，不等于全部 shape/boolean 语义已有无损 GUI 编辑或自动迁移。

严格 `version = 2` 还会拒绝重复 section/key（大小写不敏感），因为旧 INI 读取器会用后值覆盖前值；错误在创建几何对象前给出位置。旧版仍保留兼容行为，升级前必须人工消除重复声明。GUI 对空的未知 section、未列在 `[layers]/names` 的 `[layer.*]`、重复 section/key 均阻断可编辑生成，不能把它们静默丢弃。

### M0-3B3 GUI 字段往返工作区进度

hierarchical 普通体积的 `vis.color`、`vis.alpha`、`vis.visible`、`vis.wireframe` 与 `cut.gamma`、`cut.e-`、`cut.e+`、`cut.proton` 当前已在 GUI parser/模型/writer 中保留并写回；`trd` 的 `dx1/dx2/dy1/dy2/dz` 还可在层级表格中编辑。`cut.*` 仍要求同一体积设置非空 `region` 和正长度；未知 `vis.*`/`cut.*` 不会被静默写成别的字段。小型 fixture 和默认复杂源均通过“读取 → 写出 → 再读取”语义比较及源/生成文件真实后端运行；默认复杂源的 GUI package 完成 3/3 事件。GUI 现可在当前可编辑子集里保留 `[global] version = 2`，项目快照和 writer 也能写回；严格源/生成文件各用真实后端完成 2/2 事件。其他 shape/boolean 的完整无损往返及自动迁移尚未验收。
