# 工作区布局与外观（J1 实施候选）

2026-11-01：原生停靠布局、主题和 3D 外观调节已进入实施候选，J1 阶段尚未关闭。组件检查及部分窗口观察不替代整阶段验收。

## 调整工作区

“视图 → 工作区布局”提供“配置编辑”“运行观察”“结果分析”三个预设，以及保存、恢复、复位和各面板的显示开关。配置编辑以配置和 3D 为主；运行观察额外显示日志；结果分析显示配置及结果。预设只安排区域，不会替用户生成包、运行模拟或切换项目。

配置编辑、3D、结果、运行日志和预留的 AI 区域使用 Qt 原生停靠面板。拖动标题栏可调整停靠位置或浮动，拖动分隔线可改变大小；关闭面板只是隐藏，可从工作区布局菜单重新显示。侧栏仍保留原有页面入口；配置中的“显示 3D 视图”也可找回 3D 面板。

“保存当前布局”保存本机界面状态；“恢复已保存布局”恢复该状态；“恢复默认布局”移除保存布局并回到配置编辑预设。正常关闭、重开窗口使用本机保存/恢复链路。损坏或不兼容的状态回退到默认布局；显示器名称或可用区域变化时，浮动面板回到当前屏幕上的停靠布局，并给出提示。

布局只保存在本机 QSettings，包括布局版本、窗口/停靠状态和屏幕信息，不写入项目 JSON、F5 编辑事务或 K1 分享包。面板复用现有页面实例；移动、隐藏、浮动、主题切换不是配置编辑，不提交草稿，也不新增运行控制器。项目输入变化后，诊断陈旧与运行资格仍按原工作流判断。

## 主题与语言

“视图 → 主题”及右上角主题按钮提供浅色、深色、跟随系统三种策略；其中“浅色配色”可选“B · 晶格”或“K · 软件”。深色使用 C 夜读起始色板。明暗策略与浅色色板分别记忆：选择 K 后切到深色，再回到浅色，仍使用 K；跟随系统切换明暗也保留该浅色偏好。

配色和语言保存在本机，不随项目分享。颜色辅助区分层级和状态，运行成功、失败、历史或未验证等仍以实际文字与证据为准。B/K/C 是起始配色，不表示高对比度或可访问性验收已经完成。

## 3D 颜色与不透明度

有可用的 PyVista/VTK 渲染器时，3D 视图右侧提供外观控制：选择单个体积副本或材料，再选择颜色、调整不透明度，也可复位当前目标或全部外观。体积副本按完整对象路径区分，同名副本可分别设置；材料设置作用于相同材料标识的对象。0% 不透明度表示完全透明，100% 表示不透明。

每个属性的优先级为“体积副本明确设置 → 材料明确设置 → 自动显示”。自动显示包括世界体线框、选择强调、容器透明和径迹淡化。明确设置不透明度后，选择或显示径迹不会悄悄改变它；因此也可能遮挡内部径迹，必要时调低不透明度或复位。可见性、隐藏和剖切仍独立生效；选择强调继续使用边线。

这些设置只属于当前 3D 视图会话，不写入项目、F5 或后端 `vis.*` 配置。相同实际几何重复刷新时保留；实际网格及对象事实改变后清除，避免同名新对象继承旧外观。关闭视图会话后不承诺恢复。后端 `vis.*` 编辑与配置保存归 J2，不属于此控制面板。

没有 3D 依赖时，备用视图只显示文本并说明颜色/不透明度不可调整，不提供无效调节控件。编辑器草图仍是近似预览；后端网格显示、运行完成与物理验证各自判断，外观调整不改变任何验证结论。
