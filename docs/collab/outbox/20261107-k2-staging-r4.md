## 问题

主审受控 Windows CLI 探针在不可写父目录下调用导出：`export_project.py` 的 `tempfile.mkdtemp` 把 PermissionError 当成随机名碰撞，重试到 `TMP_MAX`；约 299 秒墙钟 / 286 秒 CPU 后仍无 staging 与目标，违反 R12 的诚实拒绝语义。

## 修复（最小范围）

- 新增 `_allocate_staging(target)`：每次导出用 UUID 唯一名 `.name.k2-<hex16>`，`os.mkdir(..., 0o700)` 独占创建；只有真正的 `FileExistsError` 允许在 `STAGING_ALLOCATION_ATTEMPTS = 5` 内重试；其余 `OSError` 立即 `ExportError('write_failed', ...)`（R12）。
- 创建成功后仍走既有 `_no_links` 检查；失败回滚；不覆盖既有目标；不改变 K1 发布器、其它分配点、路径权限或模板字节。
- 专项测试新增：PermissionError 注入（调用 1 次、耗时 < 5 s、消息含 staging、无目标与 staging 残留）、FileExists 前两次碰撞后成功、恒碰撞恰好 5 次后 R12。
