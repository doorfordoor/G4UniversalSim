## 根因

round125 步级 trace 证明 A2 没有丢能量：4×4×1 网格中「ghost 预步点位于世界根
`/ScoringWorld#0`（例如恰在单元共享面上）」的步，因世界根没有敏感探测器，
`G4ParallelWorldProcess` 不会分发 Hit，被静默跳过。修复只恢复这些步的归属，
不复制质量世界分数、不移动/膨胀几何、不按比例补齐。

## 改动（最小）

- `include/ParallelWorld/ParallelScoringDetector.hh`：新增 `Scope {Leaf, WorldRoot}`、
  `OwnerResolution {Owner, Skip, Failure}`、`ProcessLeafStep/ProcessWorldRootStep/
  ResolveOwnerStep` 与构造参数（scope、placements、world PV）。
- `src/ParallelWorld/ParallelScoringDetector.cc`：叶路径原样移入 `ProcessLeafStep`；
  新 `ProcessWorldRootStep` 只用**预步**位置，经声明盒 AABB 预筛与真实
  `G4Box`+`G4PVPlacement` 变换定位归属。`probe = pre + dir × 1e-6 mm`：严格在盒内 →
  归属该盒；仍在闭盒边界 → 共享面/棱滑行，按单元名字典序确定性归属一次；否则 →
  域外（外表面出射进真空/外部/gap）跳过。结构不一致 → 锁存失败并 AbortRun。
- `src/ParallelWorld/ScoringParallelWorld.cc`：`ConstructSD()` 额外为 ghost world 根
  创建并挂 `ParallelScoringWorldSD_<world>`（WorldRoot scope）并复核绑定；叶 SD 不变。
- `include/ParallelWorld/ScoringParallelWorld.hh` 未改。

物理量不变：剂量/注量仍来自 ghost 步与声明的参考质量/体积；仅恢复归属。
