## 采纳和纠正

- 采纳体积副本/材料两种作用域、颜色和百分比不透明度、单项/全部复位及缺渲染器时明确不可用。颜色按真实完整touchable标识区分副本；不以显示短名混淆多个实例。
- 显式用户不透明度优先于选择、隔离、径迹自动淡化；按属性分别继承“体积副本 → 材料 → 自动样式”，调整颜色不抹去其他不透明度设置。
- 修改了仅按现存key保留覆盖的建议：几何内容身份变化即清空旧覆盖，包含真实mesh points/faces；相同名字/边界不足以证明同一几何。相同几何刷新保留当前视图设置。
- 外观覆盖只在当前视图实例有效，不写项目、F5事务、K1配置包或后端vis字段。保存后端颜色属性和完整编辑能力归J2；J1本机持久化对象是工作区布局及主题。
- 深色C与浅色B/K分别和系统主题策略组合，避免把“系统”误称第四套配色。布局保留原业务控件，不新增运行/事务所有者；AI面板明确尚未接入。
