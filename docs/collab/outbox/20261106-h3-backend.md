## 3. 需要主审裁定的偏差与限制

1. **R-RUNTIME 的 hits 文件**：合同 §8.2 写「hits CSV 存在且 0 行」。实际
   `OutputManager` 惰性创建 hits 文件（首次 `WriteHit` 才打开），平行世界独占命中时
   hits 文件**不存在**；`event_edep` 文件存在且 2000 行全 0。测试接受「不存在或仅表头」，
   未改产品惰性语义。需主审确认合同表述。
2. **Stage B 负例不可构造**：声明几何与内核几何同源，材料/尺寸/世界盒一致；受支持的
   输入无法制造 Stage B 失败。未加测试注入 hook。Stage B 正例每次启用运行都执行
   （Stage B 不通过即非零退出）。需主审确认是否接受「代码审阅 + 每次运行正例」。
3. **Case M 线程分配**：合同 §8.6 要求「逐 worker 文件与跨 worker 相加」，但 Geant4
   调度小事件数时可能把两轮都放在同一 worker。测试断言 250 事件合计、逐 worker 文件
   存在、每行质量一致，不把调度分布当失败（合同也写明调度差异属 inconclusive）。
4. **材料别名支持**：并行几何文件允许主材料文件里的别名（如 `water`）。为使
   `Construct()` 不依赖全局 `G4Material` 名字，`ResolveMaterials` 现在把
   `MaterialManager::GetMaterial()` 解析出的 `G4Material*` 存入配置；这是对合同
   §3「材料名在主材料文件中存在」的自然实现，不属于范围扩张。
5. **未验证**：ROOT、biasing、电磁场、`[scoring.mesh.*]`、LET、DDD 均为显式拒绝而非
   支持；Linux/CI 未运行（本机 Windows only）；H3-4 统计基准未做，因此本阶段不声明
   物理正确性，只声明接线、单位、归一化与隔离路由。
6. **GUI**：`[parallel_world]` 标记 `external_only`，GUI 生成器不写该段（H3-3）。
