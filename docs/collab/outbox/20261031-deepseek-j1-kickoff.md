## 1. 默认区域布局与三个预设差异

默认布局采用"左导航 + 中主区 + 右属性/诊断 + 底部输出"的四区结构，全部为 Qt 原生 QDockWidget。中主区承载 9 页 QStackedWidget 的主内容；右区默认宽约 320，停靠 Config/结果/日志/未来 AI 任务区；底部日志高度约 180。左 220px 侧栏按既有约束不动，只在新主题下重排图标与文字间距。

三个预设只切换 Dock 的可见性、停靠位置与尺寸比例，不触碰任何业务状态：

- **配置编辑**：右区以配置/环境 Dock 为主，底部日志压到最小可读高度；中主区聚焦编辑页，强调"改动在此发生"。
- **运行观察**：底部日志、右区诊断 Dock 同时展开，中主区切到进度/监控页；右区顶部放运行状态摘要（只读，来源于 runner 现有信号）。
- **结果分析**：右区收窄为属性面板，中主区给结果视图更大宽度；日志与 AI 预留区默认隐藏或浮动。

预设只写本机 UI 设置（`saveState/saveGeometry` 及屏幕信息），绝不进项目 JSON、F5 事务或 K1 分享包。窗口/主题/预设切换不提交配置、不丢草稿、不启停模拟，不新引入进程或事务控制器。

## 2. B/K/C 色板到桌面层级与现有模式

原始 CSS 仅作文本参考，绝不照搬 1.95 行距与全卡片化。映射原则：**B 作浅色桌面默认、K 作浅色专业/高对比备选、C 作深色桌面基准**；`system` 模式按平台外观在 B/K 与 C 之间切换，与 `ThemeColors` 的 light/dark/system 一一对应。

- **层级**：B 的 `bg=#fff / card=#F5F9FA / line=#E1E7EB` 表达"画布—面板—分隔"三级，正好对应 QMainWindow 背景、Dock 面板、Dock 边界。K 类似但略冷（`bg=#F8F9FA / card=#EDF1F5`）。C 的 `bg=#111820 / card=#172029 / line=#26313D` 用于深色。
- **边界**：`line` 只用于 Dock 标题栏下沿、分割条与分组间细线，宽度 1px，避免整块描边。默认不把每张表、每个块做成卡片；面板只在层级确实需要时用 `card` 底色，不做圆角+阴影堆叠。
- **强调色**：B 的 `accent=#0E7C86`、K 的 `accent=#1971C2`、C 的 `accent=#8CC8F0` 只用于链接、当前选中 Dock 标签、主按钮底色与焦点环；`strong` 与 `hl` 用于同色系的加深与高亮背景，不跨色相滥用。C 的 `hl` 是半透明暖色，仅用于深色下"需要区分但不强调"的选中行，不做状态色。
- **字体**：系统字体优先，保留 DPI 缩放，不写死 CSS 字族顺序；`core/theme.py` 已集中 ThemeColors，把上述语义 token（surface/panel/line/accent/muted）延伸到 ThemeColors，再由 theme 统一喂给 QSS。

## 3. 信息密度与状态语义

- **高密度表格**：沿用系统行高（约 22–24px，随 DPI），行内左右内边距紧凑；表头弱化（`muted` 文字 + 下边 `line`），不斑马纹、不整表描边。数值列右对齐、等宽感，单位用次一级文字。表内不使用卡片色。
- **主/次按钮**：主按钮仅"运行/开始/应用"等当前页唯一主责动作使用 `accent` 实底；次按钮描边透明底；危险操作用文字 + 图标 + 位置区分，不只靠红。
- **错误**：错误行左侧加图标列，行内用 `strong` 加深文字，悬浮提示给全文；错误块顶部加细左边框，但颜色只作辅助——文字标签"错误"始终显示。避免出现只有红底无文字的状态。
- **运行/物理验证状态**：运行状态（排队/运行/完成/中断）来自 runner 现有信号；物理验证状态（未验证/已核对/待复核）单独一列/一徽标，二者不合并。文案明确写"运行成功"≠"物理正确"，避免色块替代语义——`accent`/`hl` 只提示"关注"，不对"正确性"上绿色。

统一原则：任何状态都必须同时有文字或图标，颜色只做冗余线索。
