### Windows（源码入口）

1. 干净检出本候选，打开 “x64 Native Tools Command Prompt for VS 2026”（或开发者 PowerShell）。
2. `cmake --preset vs2026-x64`
3. `cmake --build --preset vs2026-release`（产物 `build_vs2026/Release/G4UniversalSim.exe`）
4. `build_vs2026\Release\G4UniversalSim.exe --check-geant4-data` → 期望 `required_complete=true`；
   缺数据时设置 `GEANT4_DATA_DIR` 或按 README 数据三法。
5. 最小运行：`build_vs2026\Release\G4UniversalSim.exe --config config\main.ini --output <临时目录> --dry-run`
   然后去掉 `--dry-run` 跑小样本；期望 `run_summary.txt` 有 `status = completed`、完成事件数等于计划数。
6. GUI：`cd gui; python -m venv .venv; .venv\Scripts\pip install -r requirements.txt; .venv\Scripts\python main.py`；
   按中文入门 §1.6 七步检查开始页→Project→Configuration→校验→小样本→摘要→保存配置包。
7. 已安装包入口：运行安装程序（含数据页）或在 `bin\geant4-data.txt` 写数据路径；`bin\G4UniversalSim.exe
   --check-geant4-data`；GUI 从开始菜单/`gui\G4UniversalSimGUI.exe` 启动。

### Linux（源码入口）

1. 准备 Geant4 11.3.2 前缀（conda-forge/micromamba 或系统包，含数据；`$G4_PREFIX`）。
2. `cmake -S . -B build_linux -DCMAKE_BUILD_TYPE=Release -DCMAKE_PREFIX_PATH="$G4_PREFIX"`
3. `cmake --build build_linux -j"$(nproc)"`
4. `./build_linux/G4UniversalSim --check-geant4-data`、`./build_linux/G4UniversalSim --capabilities`
5. 最小运行与摘要同上；GUI 依赖 `gui/requirements.txt` + 系统库
   `libegl1 libgl1 libxkbcommon0 libdbus-1-3 libfontconfig1`，`QT_PLUGIN_PATH` 指向 PySide6 自带 `Qt/plugins`
   （见 `docs/Linux构建与验证.md` §7）；显示环境用真实 X11/xcb。
6. 缺依赖恢复：缺数据 → `--check-geant4-data` 报缺项后设置 `GEANT4_DATA_DIR`；缺 Qt → 安装系统库并重开 GUI；
   缺 SDK/编译器 → 按中文入门先决条件装 SDK 或改用安装包 runtime 入口。
