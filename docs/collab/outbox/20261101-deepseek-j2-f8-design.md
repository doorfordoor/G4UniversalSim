## 回信中建议采纳的设计

1. Start 空白创建、模板创建、导入三个同级入口，五模板继续保留；Project/配置页显示文档身份、创建方式、文件来源、未保存状态与校验状态，不能把未保存等同校验失败。
2. 多源、材料/元素及多体积采用列表加详情，保留选中行草稿；短表单用 QFormLayout 和滚动区。高密度/新增列表可采用 QTableView + model/delegate，避免重写已有稳定表格造成无关迁移。
3. 物理页呈现 reference、模块操作和有效组合差异；“拟应用”与绑定当前 revision/运行证据的“后端观测”分组显示。缺观测明确写未观测，不能用注册调用或字段存在补成已生效。
4. 可编辑、只读保留、实验性、不可用有文字说明；集中翻译、稳定 token 和主题 palette，键盘、错误定位、DPI 及向导重入纳入独立桌面验证。

## 本地审阅：必须纠正或细化的回信意见

| 原回信问题 | 本地建议及原因 |
| --- | --- |
| 体积区放球面/体内采样 | 移到源详情的空间分布；实体形状与 GPS 采样位置是不同对象。Surface Sphere 只在后端真实支持时可生成，不能因此新增尚未支持的球体内部类型。 |
| “材料组分只能选有密度材料” | 限制只针对体积分数。质量分数和原子数模式须按实际材料契约允许适用的元素引用；自建元素/同位素不可被NIST候选覆盖。 |
| 未知字段禁用保存/导出 | 区分项目快照保存、editable writer、显式source-copy、K1证据导出。非法/未知草稿应可保存恢复；不能无损生成时阻断editable writer。source-copy必须用户显式选择并保持原有契约；不能承诺所有未知输入都可运行，也不能一概关闭合法的保存或证据导出。 |
| `ProjectDocument`、`SourceCapture`、有效模块槽等像既有接口 | 仅作概念名，不宣称源码已有这些类/协议；复用现有项目/文档与来源捕获字段，新增接口由主负责人确认。 |
| 把完整NIST元素查询放为可推迟项 | 本轮明确范围要求元素搜索和来源辅助，快捷材料列表不能代替。实现可先静态候选目录，但需标版本/未知，并由真正后端解析验证，不缩减整项验收。 |
| E7在顺序中排第一、未就绪先占位 | 只有实体相关编辑依赖E7；先完成无文件创建、材料与多源。占位不可计作高级实体交付。field/bias按各自真实能力，不受无关实体重构阻塞。 |
| 空白新建无条件额外确认、材料/源全空 | 入口操作本身不必重复确认；旧草稿将被替换时才显示差异/保存选择。无源文件不等于无粒子源，初始源是空列表还是显式单源草稿须裁决；空列表不能生成假成功包。world默认值必须可见可改，不隐含demo。 |
| 向导重入“只改当前字段” | 多源/高级配置未必能映射回有限 WizardSpec；须有字段所有权和可表达性检查，不能用默认模板重建整个项目而静默丢高级数据。 |

## 建议给实现者的信息架构与状态契约

### 页面与组件落位

不增加顶级运行入口或第二状态所有者。Start 三入口；Project 显示项目与材料/几何文档来源摘要；ConfigBuilder 内现有区域扩展材料/元素、体积、源、物理、场/偏置；保留 F4 诊断区和现有 Run/K1、结果页。左结构导航可先作为现有页内导航，避免为统一视觉而一次重写全部页面。

- **材料/元素**：元素搜索按符号/名称/Z，候选显示自建/NIST/版本状态；同名自建优先。选择候选是显式动作，拼写错误不自动修复。组分选择按模式过滤候选，体积分数只选有密度材料；来源在保存重载后仍可解释，未知后端解析状态保持未知。
- **源**：列表包含稳定身份、名称、启用、类型、强度；位置/角度/能谱在详情分组。选源/同发是源集合级模式，不放单行造成互相矛盾。复制生成新ID/名称，重命名不换ID；删除提示引用影响；排序不得无声改变强度或同发语义。
- **体积/计分**：体积选择及敏感性编辑与逐体积结果入口关联；展示volume/SD/事件身份，不为所有体积冒称独立SD。过滤/能谱等H2能力不借本轮入口提前开放。
- **物理**：基础 reference + 操作表（模块、类别、附加/替换、目标、诊断），独立 manual 模式。类别不明不猜槽位；模式切换不丢草稿，生成前整体校验冲突；region 限制与真实process证据单列。
- **高级实体**：E7元数据提供参数、单位、约束与支持状态；未知参数保留原始输入并阻断不安全写出。后端vis输入与J1本机外观分组，并标明“保存到仿真配置”或“仅本机显示”。
- **场/偏置**：场详情显示类型、单位、坐标/区域、积分参数及已实现依赖；偏置规则表显示粒子、process、体积、倍率/权重与启用。依实际schema/后端元数据决定字段，不凭设计增造字段。空hook、未知目标、初始化后非法修改必须阻断；运行证据显示匹配/挂接/未验证的区别。

### 创建与向导状态迁移

`现有工作区 → 候选草稿（空白/模板/导入） → 检查替换差异 → 现有事务提交`；候选取消/校验拒绝保持旧工作区完全不动。提交后的非法草稿由F5保存与恢复，不伪造“校验通过”。操作后使相关K1证据陈旧。新建与恢复不得串用旧材料/几何路径或同名对象身份。

向导“返回”保留页草稿；Esc丢弃当前未提交候选。已提交后重入先检查能否表达当前设置：可表达时回填；存在高级内容时明确列出将替换范围，由用户选择在编辑器继续或确认替换，不能静默丢弃。运行中的新建/替换沿用既有mutate guard，环境设置打开与返回不修改文档。

### F8可实现细节

表单用label buddy、明确accessibleName/说明和稳定Tab序；错误跳转先展开/切到对应区域再聚焦字段；列表删除后焦点落相邻行，关闭搜索/环境对话框回原入口。快捷键复用现有Ctrl+N等映射，新增助记键先查冲突，不凭设计覆盖已有动作。状态有文字/图标，不能只靠色彩。

100/125/150/200%均列实际验证目标，记录有效工作区而非只截图像素。当前最小1200×760在高缩放小屏可能放不下：优先页内滚动、非关键列收缩、详情折叠和按钮可达，是否下调最小窗尺寸由负责人结合实窗裁决；不先声称所有缩放已支持。浮动dock回收/恢复不得创建新控制器。布局语言主题走本机设置，不能进入项目事务或分享包。
