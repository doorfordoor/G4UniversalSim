## 统一契约

1. 编辑快照包含完整业务模型、材料/几何草稿和来源阻断依据、必要原始输入；撤销/重做不从磁盘重载覆盖草稿，不将非法数值清成默认。持久格式严格版本化，未知/冲突/重复 JSON/nonfinite 拒绝，旧项目兼容保持。保存点只有写入成功后更新；失败不丢 dirty/历史。
2. 一个用户语义操作是一个事务。连续同字段输入可以合并，但保存、失焦、结构变动、撤销或分支切断合并。提交失败不改当前快照、历史、revision；Undo 后编辑清 redo。历史有明确容量上限，dirty 以保存快照身份判断，不以栈下标猜测。
3. 状态恢复刷新现有页面、失效诊断/Inspect/后端几何与运行包；revision 单调，不因撤销回到旧值而复活旧回调或旧运行成功。运行和证据不是编辑历史。只操作自身进程，不以进程名结束应用。
4. 自动保存与手动项目保存分离：每会话独立恢复文件，原子发布；未命名项目同样保护；失败非模态可见。启动/菜单允许明确恢复、保留待后、丢弃；损坏/不支持文件保留并说明。活跃会话受锁保护，不靠 PID 单值或过期时间抢占。
5. 恢复作为未命名副本，始终重新校验/生成，不覆盖原项目或源配置；源变化须可见且保持既有生成门禁。正常关闭/切换时保存、放弃或取消语义明确；失败或取消不清恢复文件。自动恢复不执行任何配置、宏或仿真。
6. UI 使用集中翻译/主题；撤销范围和 autosave 状态有文字。采用 DeepSeek 已返回设计中适用于本单窗口程序的部分，逐项核实 API，不照搬多标签或不存在的 Qt 属性；不增加不必要的设置系统。
