## 行为与设计

在现有 Run Console 提供清晰的“连续运行会话”入口。一次启动保留同一个后端进程，用户能够完成 A/B/A 三轮；进程存活、会话空闲、本轮运行、轮次完成、整个会话退出是不同事实。默认普通运行保留原有行为。

DeepSeek负责布局与交互设计。使用已有皮肤、区域层次、字体和翻译封装，正文用直接可读的中文。面板清楚分成当前会话/本轮、下一轮参数、轮次记录及操作反馈。只编辑后端实测允许的简单单源字段和事件数；几何、材料、物理、线程、输出根等显示“需新建会话”，不伪造热修改。源模式超出白名单时明确说明，保留旧单次运行入口。

“草稿”“待后端确认”“后端已接受”“被拒绝”“需重新启动”由实际回执驱动。配置接受不等于内核已采用；没有消费者证据时用“本轮提交参数”等准确用语，详细证据可查看，不能把源码缓存读回标为物理验证。前端草稿 revision 与后端 revision 分开；拒绝不能使界面显示已生效或悄悄在下一轮补执行。
