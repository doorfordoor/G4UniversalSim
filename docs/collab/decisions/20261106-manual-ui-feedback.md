# 人工使用反馈：几何层级、配置导航与物理列表简介

记录日期：2026-11-06（Asia/Shanghai）。来源：用户转述的人工使用反馈。
状态：已记录，待前端改进排期；尚未实施或验收。

## 反馈 1：几何体积树

原意：体积（几何）的配置项建议也做成树状形式，方便观察子母体积。

目标：以树状层级呈现母体积与子体积关系，便于展开、折叠、定位和选中需要配置的体积。
后续验收关注：树中层级与实际几何父子关系一致，选择节点能定位对应配置；层级较深或体积较多时仍便于浏览。

## 反馈 2：“配置”下的直接导航子菜单

原意：源、几何、材料、物理列表、3D预览等配置项目，参考成熟物理仿真软件（如 COMSOL）的 UI，做成左侧“配置”下的子一级菜单，方便直接选中。

目标：左侧“配置”为父级，源、几何、材料、物理列表、3D预览等为其直接子菜单，用户可直接选择目标项目；COMSOL 作为导航组织方式的参考。
后续验收关注：这些入口在左侧可直接发现和选择，选中状态与当前内容一致，切换时保留现有编辑状态和验证行为。

## 反馈 3：物理列表选项的悬停简介

原意：选取物理列表的菜单可以配上该物理列表的简介，例如将鼠标放在该选项上时显示简介。
状态：未开始，待排期。
目标：每个可选物理列表提供简短、易懂的说明，优先采用选项悬停提示，帮助用户理解并选择。
后续验收关注：简介与实际可选列表及受支持的 Geant4 版本对应；说明主要用途和适用边界，不把名称或可选状态当作物理验证证明；展开菜单后悬停可读，中文显示完整。具体文案在实施时核对官方资料与实际后端。
