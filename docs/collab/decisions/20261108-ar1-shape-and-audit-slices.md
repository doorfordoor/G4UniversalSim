# AR1 后续切片实施与验收清单

依据AR0 r3与总规划§6，接在几何加载事务独验通过之后。各切片独立冻结、验证与签收，不以本清单代替完成证据。

## box/tubs 规范参数

将明确形状参数提取为值对象/规范解析入口，由文件读取与C++ VolumeNode构造共同消费；保留现有注册表、INI别名、全长/半长、角度单位和boolean tool约束。其余形状维持显式兼容路径，不扩全部形状重构。规范化不另存一份可失步的权威可变状态。

允许文件：Geometry域描述/校验/构造源码与头文件、必要窄探针及测试、对应CMake/runner注册；每项新增文件要进入源码跟踪和构建/导出闭包。源语法诊断仍保留文件行号，不把Builder的C++兼容shorthand误开放给INI。

验收：直接代码构造与INI构造分别覆盖box/tubs正反例，boolean tool、别名、参数优先级与既有兼容输入；实际G4Box/G4Tubs尺寸读回一致，非法输入创建对象前拒绝。运行geometry_safety/diagnostics/a5、effective_geometry_materials、roundtrip、default_geometry。实际构造路径改变后按共享语义分析H3边界及K2 S-A/S-B影响，保存判断与必要真实回归，不用预览替代内核结果。

## 关联审计小切片

- R1-AUD-11：共享region cuts不得被后体静默覆盖；按原审计关闭条件处理相同/冲突cuts及顺序交换，读取实际内核cuts。不得通过顺序偶合或文案修订关闭。
- R2-02：零孔隙率及正小值舍入为零时按实际孔数生成无孔几何；保持非零、禁用孔层、同seed确定性。隔离真实后端读取生成包并初始化，保持空副本拒绝。
- R2-03：几何长度采用可往返精度；300um分7/11及非整齐厚度满足原后端容差，保留默认10、1/5及非法0片，实际后端初始化。新产物与旧科学证据身份分开，不放宽容差。

实现与独验分离，单文件单写者；运行正式候选期间禁止改其源码/测试。每项失败原记录保留。新候选显式通过源码跟踪、首尾身份、原日志计数/SHA门禁。AR1整体全部满足后由当前主审签收，再进入AR2；MR1必须AR1–AR3均实际完成才执行。
