# 人工使用意见：先新建模拟，再配置和运行

记录日期：2026-11-08（Asia/Shanghai）。来源：用户直接反馈。
状态：已记录，未实施，待后续交互设计与排期；不恢复架构实施或功能开发。

## 用户原意

> 参考成熟工程软件，新建模拟可以作为窗口，先“新建”然后才能“配置”、“运行”，可在左上角增加另一“新建”入口。

## 后续设计目标

1. 将“新建模拟”设计成清晰的窗口流程，使创建模拟成为进入配置、运行流程的起点。具体采用对话框、向导或其他窗口形态，后续设计时确定；本条不默认要求多个独立主窗口。
2. 尚未建立当前模拟时，界面清楚引导用户先新建；配置、运行入口按当前模拟是否存在及对应状态开放。创建成功后进入该模拟的配置流程，运行仍须满足现有校验和执行条件。
3. 在窗口左上角增加易发现的“新建”入口，与已有新建入口共用同一业务动作，避免形成两套创建逻辑。

## 实施时需保护的既有行为

以下为后续设计/验收注意点，不表示本轮已经修改产品：

- 打开已有项目应建立有效的当前模拟上下文，不要求用户重新创建并覆盖旧项目。
- 取消新建、创建失败或处理未保存修改时，旧项目和原始草稿保持正确；不得先清空当前数据再询问是否保存。
- 先新建不等于允许立即运行；无效配置仍需被原验证流程拒绝，运行中创建/切换项目沿用既有忙状态与任务身份规则。
- 左上角入口、原菜单/快捷键与其他新建入口行为一致；操作完成后当前模拟名称、配置内容和可用操作对应同一项目。
