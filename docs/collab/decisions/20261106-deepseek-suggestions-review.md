- 新建原生验收启动器、扩大截图矩阵等：本轮不采纳为前置，也不扩展验收工具。

- 旧 J2/J3 计划中的未验收状态不代表当前状态；阶段判定仍以 ROADMAP 与 CURRENT-SUPERVISION 为准。
