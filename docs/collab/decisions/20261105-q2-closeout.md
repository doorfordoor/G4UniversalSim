# Q2 科研基准与适用范围固定清单

依据 ROADMAP 与 20261102-science-stage-playbook.md。2026-11-05，E4关闭后冻结。现有Dose/Fluence/LET/DDD、事件不确定度、XS偏置为范围，新增过滤与平行世界归后续H2/H3。

| 项 | 完成标准和证据 |
| --- | --- |
| Q2-1定义、参考及预注册 | 当前量的消费者/单位/归一化/权重/质量/体积定义与独立参考表；列有限病例及适用域、数据版本/原文件SHA、原始观测量、独立计算路径。按实际依据预先确定样本数、种子、统计比较、容差、停止条件，经独立复核冻结后运行 |
| Q2-2确定性单位和实现比较 | 四个量各有均匀体或可解析小例；对沉积能/本体质量、路径长度/体积、LET比值分子分母、NIEL长度谱独立复算。重复权重、质量或体积因子能被反例发现，保存原始量与比较器 |
| Q2-3独立参考与适用域 | 按Q2-1冻结参考逐例运行，报告数值差、统计误差及通过/失败/限制。区分实现折积与NIEL表本身的独立验证，材料/粒子/能域声明可追溯 |
| Q2-4统计不确定度 | 预注册种子和独立批次；检查事件内合并、零事件贡献、N<2、零分母、稀疏worker、多线程合并和LET比值相关。输出估计方法与覆盖证据，样本不足按预定规则处理 |
| Q2-5 XS偏置与analog | 同几何/源/截面、独立批次，实证worker过程绑定及权重；比较加权均值/透射或沉积、统计误差、耗时与效率，保留异常种子及适用条件 |
| Q2-6审查、平台矩阵与交班 | 按影响完成Windows/Linux支持版本回归、严格证据和实际云结果，最终候选/原输入/输出身份明确，更新量定义/支持矩阵/基准说明及阶段状态，集成后启动H2首项 |

统一证据写D盘，C盘独立复核。科学比较独立于界面与进程退出判定，原始失败保留。清单冻结后按既定显著缺陷规则处理。
