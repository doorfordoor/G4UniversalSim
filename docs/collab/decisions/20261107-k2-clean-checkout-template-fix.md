## 最小实现范围

- `core/export_project.py` 的模板枚举、源模板读取/身份/复制辅助；`packaging/build_export_template.py` 复用同一逻辑；原静态专项；重生成正式模板manifest；必要两处说明与作者r2回执。
- 模板成员遵原目录/扩展规则，`tools/` 为原9个直接成员；排除其下协作目录，不依赖开发 Git 才能从安装模板导出，不把本地协作脚本加入产品，不删除本地文件。
- 模板是受控文本闭包，其正式复制内容统一CRLF→LF后计算原 SHA/路径行算法；清单的SHA、bytes及digest描述实际将复制到导出树的规范字节。只允许模板源内容规范化，禁止借此放宽最终导出原始文件SHA验证。安装模板已为规范字节，再导出保持相同身份。
- S-A项目输入及README仍逐字节保留，main.ini仍只替换白名单值；不得把模板规范化扩大到项目输入、CSV或用户文件。`src/`、`include/`、main.cc 原文件不改写；底层K1/物理实现/全局Git及系统设置不改。
