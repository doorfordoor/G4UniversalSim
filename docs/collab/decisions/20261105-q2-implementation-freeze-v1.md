## 数值与状态

同一汇总行恒等式的比较必须计入12位有效数字写出误差。对非零输入x，按已知12位有效数字取半宽0.5×10^(floor(log10(|x|))-11)，传播到独立计算结果；不能按打印字符串的末位小数位估界（整数2000同样有12位有效数字的精度），显式零按状态和零值契约检查，再加机器舍入界，不用固定1e-12相对误差误判合法打印值。跨CSV累加沿原1e-9相对界并记录求和路径；任何高于1e-6的算术差异均失败。近零比值误差使用矩区间传播及绝对界，不能随意clamp严重负方差。

N、质量、体积、估计量ID、错误状态和表SHA必须实际核对。REF-FLU-01的宽束原规格存在单位与随机命中混淆：1cm^-2=0.01mm^-2；12×12mm平面源、N1000的期望总注量是1000/144mm^-2且有二项波动。这些数值不得被本冻结误用为确定性门槛。
