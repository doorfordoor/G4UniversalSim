# R28 探针计数口径升级提案与检查点

问题：v2按目标文件的全局Assert行号匹配所有frame，any/all生成器、推导式和lambda在同一源码行上的内部line事件被误算。轨迹短路顺序仅变化即可出现24448/24446，不能视为科学断言减少，也不得填充断言或修改归档报告。

实施范围：tools/test_assert_probe.py、scripts/check_report_evidence.py、scripts/test_report_evidence.py；runner的PROBE_ID由主代理同步。先不运行Geant4。

v3规则：按AST词法作用域关联实际函数/类/module帧与本作用域Assert行，拒绝没有Assert语句的表达式帧（genexpr/listcomp/setcomp/dictcomp/lambda）；普通generator函数只要含真实Assert仍计数。单个Assert跨度内的表达式重复line事件不重复计数。同一行多个Assert是行入口下界，不计为内部元素个数；含前置if/for等而无法可靠区分执行入口的同一行采用保守不计，不能把未执行分支算作断言。新线程沿用threading.settrace。

版本settrace_assert_lines_v3；checker默认仅接收v3，v1/v2只用于显式--allow-legacy-probe归档核验。baseline必须同probe，跨v1/v2/v3即使开启legacy也拒绝；同probe总数、逐例、非零、日志摘要等门禁保留，不追改旧证据。

验收：短路顺序、全部表达式帧、用户generator真实assert、线程、同一行函数定义/多个assert/不执行分支、异常与SystemExit、同代/跨代baseline；运行真正probe子进程。保存v2/v3同一小fixture对照，证明计数变化是口径修复，不是覆盖回退。主代理随后在4e6及当前候选分别以同v3重建完整基线与对照。

## 实施与冻结（2026-10-29）

- v3按AST本作用域收集Assert，作用域以code name/firstlineno匹配（包含装饰器起始行）；module不会把同一行函数定义当成函数体assert。genexpr/listcomp/setcomp/dictcomp/lambda没有Assert语句，排除其frame；命名generator不排除。
- 每个被跟踪frame保留当前Assert的[start,end]源码跨度，在跨度内返回起始line的表达式事件不重复计数，离开跨度后才允许下一次入口。此规则也覆盖内联推导式重复line事件。它仍是保守行入口下界：同一行多个assert至多记一次；前置if/for/赋值与assert共享行、无法可靠辨认入口时省略。没有改成声称“精确科学断言次数”。
- checker默认v3，v1/v2只显式allow-legacy-probe。报告内每个passing case的probe须与报告一致；baseline报告和有count的case probe均须同代，legacy开关也不能允许跨代比较。同代total/逐case/零断言/日志hash门禁保留。
- 正式test_report_evidence新增15个真实probe子进程fixture：短路顺序、四类表达式与lambda、multiline/nested checks、普通generator、同一行yield、assert内yield、inline定义/条件/多个assert、decorator/class、新线程、AssertionError/RuntimeError/SystemExit。跨probe双向拒绝与两种legacy同代通过均有反例。
- 实测`python tools/test_assert_probe.py scripts/test_report_evidence.py` exit0、G4USIM_ASSERTS=77；归档89例v2报告用`--allow-legacy-probe`原样复核exit0，未编辑任何历史报告或日志。定向diff检查通过。
- v2/v3小fixture证据：`out/verification/r28-probe-v2-v3/report.json`。同样一个short-circuit assert：v2 first=2/last=6，v3两者=1；三个comprehension assert：v2=21、v3=3；真实用户generator内assert：两者均4；multiline两者均1。原v2探针从4e6fa7a导出到新目录，未替换历史文件。

源码已冻结，可同步runner ID并开始同v3基线重建。`scripts/test_m0_runner.py:42`另有v2字面量，属于root协调范围，已提示一并改v3；本代理未越权编辑。
