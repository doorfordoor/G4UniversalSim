## 定位与解释修正

1. `src/Scoring/LETScorer.cc:74`—76只按有效步和粒子名筛选，不区分初级与次级质子；112—113分别计算A/B、C/A，其中B=Σwl、A=ΣwlS、C=ΣwlS²。由此严格得到LET_d/LET_t−1=CB/A²−1，即按wl加权的步阻止本领变异系数平方。只保证非负，**没有普适的5%上界**。现有原始矩给出的100MeV变异系数平方为0.2106459508，与直接比值一致。
2. v1冻结使用FTFP_BERT_EMZ，而原参考提案采用仅电磁option4。冻结时把完整强子物理的混合质子步分布与窄能谱的5%辅助假设配在一起，依据不足，这是实验设计问题。PSTAR电子阻止本领是碰撞阻止本领；其核阻止本领指弹性反冲能量转移，不能把该表当作完整强子反应次级混合谱的剂量平均LET参考。[NIST量定义](https://physics.nist.gov/PhysRefData/Star/Text/appendix.html)、[PSTAR输出及方法](https://physics.nist.gov/PhysRefData/Star/Text/programs.html)。
3. 原回执的“保守独立z≈0.96”表述撤回：两个估计量相关，忽略协方差并不必然保守。现有矩足以各自重算误差，但未给出两个比值差的全部协方差，不能用该z解除原失败。
4. “少数高LET步骤/次级主导”保留为待检验解释。聚合矩提示分布较宽，不能单凭聚合矩确定次级贡献比例或尾部事件数量。没有改粒子过滤、cut或物理实现的依据。
