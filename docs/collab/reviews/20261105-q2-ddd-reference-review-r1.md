## 确定缺陷：不成立的能量区间

`out/collab/q2-reference-ddd-v1/compare.py:637`声称步平均动能必在[pre−Edep,pre]，646行据此构造伪post，671/676行再用该区间及新增5%宽度判完整折积。此推导不成立：局部沉积不包括显式次级带走的全部动能，不能代替步前后动能差。[Geant4官方步数据定义](https://geant4.web.cern.ch/documentation/dev/bfad_html/ForApplicationDevelopers/TrackingAndPhysics/tracking.html)明确区分这两个量；本项目`src/Hits/ParticleHit.cc:172`记录pre动能，`include/Scoring/DoseContext.hh:33`使用实际pre/post平均。

能量账本合规的**合成反例，非本次实测步**：pre=100MeV，post=99.899MeV，局部Edep=0.001MeV，次级携能0.100MeV。前后差0.101=0.001+0.100；真实平均99.9495，落在声称的[99.999,100]之外。现有CSV不能凭Edep恢复完整平均能量，不能据此建立“精确上下界”。

## 观测限制：hits不是全部计分路径

`src/Hits/SensitiveDetector.cc:92`—116在零沉积命中关闭时，仍为正路径调用DDD计分，随后返回而不保存普通hit。当前源代码语义允许两个文件记录不同的路径集合。

差异在D/C独立输出一致，与零沉积步计分但不入普通hits的既有语义一致；没有证据确定后端结果缺陷。独审最初把hits当作完整路径记录的假设也不成立，失败脚本与日志保留，不把修正后的限制称成原精确对账通过。可见事件集合也只提供下界，不能一般性等同DDD非零贡献事件集合。
