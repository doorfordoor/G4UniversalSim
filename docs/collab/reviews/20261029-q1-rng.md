# R26 安全随机命令组件提案

API 保持主代理约定：`RandomCommandGuard::Validate(command)` 与 `ExecuteRestoreIfRequested(command)`，均只在调用线程作用；非 restore 返回 false。

预检不读文件、不检查其存在，允许同 macro 先保存后恢复。按主代理明确接口决定，setSeeds 严格接受 2..99 个非零有符号long整数参数（Geant4栈数组100项还要留自动终止0），拒绝任何位置显式0、范围溢出及不完整token；负的非零long维持原生有符号参数兼容。原生setSeeds不广播worker，不承诺逐worker状态恢复。

restore 无参数沿用官方 `currentRun.rndm`；整个参数是文件路径，可整体加单/双引号，也支持未引号路径空格。语法期拒绝嵌套/不配对引号、空引用和控制字符。执行时仅允许PreInit/Idle/GeomClosed；读取文件一次形成受限大小内存快照。按主代理要求严格沿用Geant4路径规则：参数无`/`则在前面拼GetRandomNumberStoreDir，含`/`则直接采用（包括原生Windows反斜杠特例，不擅自重新解释）。不得对真实引擎调用不受检的restoreStatus；不得在临时引擎上调用可能EOF死循环的MixMax原生restoreStatus。

当前引擎为MixMax或James时，用其copy构造创建临时独立引擎，读取当前状态仅用const put。支持其原生saveStatus格式：MixMax的`mixmax state, file version 1.0 / N / V / counter / sumtot`，James的`Uvec`整数向量（含引擎ID）。严格解析完整快照，检查维度、整数范围、索引、有限状态分量与checksum，再由临时引擎get(vector)校验。不能仅信getState的bool：MixMax缺完整counter检查，James缺索引/浮点范围检查。

验证成功后只提交已经验证的内存vector，随后核对put相等；不重新打开原文件、不执行原生UI restore命令。提交异常/不一致时尽力恢复执行前vector，并抛runtime_error，由主代理现有batch/csh失败路径收尾。合法状态即使与当前状态相同也算恢复成功。其它引擎明确提示本组件尚不支持，替代setSeeds。

每事件恢复enable（true/1以及Geant4接受的真值拼写）明确拒绝，false允许；原因是没有受控worker逐事件文件快照/校验钩子，不能悄悄关闭或宣称master验证保护worker。当前单次恢复只修改当前线程master引擎，不宣称恢复所有worker。unknown initial seed不列缺陷。

验收建议由主代理后端集成：2/99/100 seeds边界、long越界、任意0、LONG_MIN；先save再restore、默认文件名、含空格路径/引用；合法MixMax/James保存文件成功，状态不变也成功；缺失/空/截断/错引擎/坏checksum/坏counter/坏索引/额外数据失败，且失败前后真实put不变；csh停止后续命令；单双worker与逐事件enable明确拒绝。单元C++可直接更换测试线程引擎并生成原生saveStatus，组件本身不替换引擎。

## 候选冻结与交付

已完成RandomCommandGuard.hh/.cc及tools/randomCommandGuardCheck.cc；目标建议名randomCommandGuardCheck。API未变。没有自行构建或运行backend exe；根代理统一构建/集成。工具覆盖原生MixMax/James保存与恢复、重复同状态恢复、空格路径/默认文件名、缺失/截断/格式/extra token、MixMax维度/counter/checksum、James索引/ID/NaN/非法常量、真实engine put保持、非法Geant4状态与setSeeds边界。

独立复核响应：James官方setSeed对负值执行seed=-seed，LONG_MIN明确拒绝；其它负的非零有符号long保留。MixMax candidate->get确实调用precalc再对照checksum；counter和每一V分量由本组件预先完整检查。James要求原生24-bit格点，cd/cm严格为7654321/2^24与16777213/2^24，不仅检查任意范围。读取固定长度后再检查EOF以发现已观察到的并发增长，但只保证提交经过验证的内存快照，不声称源文件整个期间未被外部修改。

官方G4RunManager::RestoreRandomNumberStatus仅构造路径、调用restoreEngineStatus、showStatus，不更新randomNumberStatusForThisRun缓存（11.3.2:719-732、11.4.3:736-749）。因此本组件不刷新该缓存与原生命令一致；下一run的正常初始化按内核生命周期重新保存状态。当前引擎身份保持，未安装临时引擎为真实引擎。

原生格式支持边界：MixMax version1.0与James Uvec；默认currentRun.rndm；普通文件最大1MiB（原生两种固定布局远小于此）；不支持其它engine/旧James文本格式时明确给setSeeds替代。工作线程逐事件restore enable明确拒绝，不悄悄关闭。未知初始seed不作为缺陷。

源码/头文件与工具现在冻结，等待统一构建和真实工具/后端验收。静态diff检查通过不代替编译与运行。

依据：Geant4 11.3.2/11.4.3 G4RunMessenger/G4RunManager；bundled CLHEP MixMaxRng.cc/JamesRandom.cc。当前只实现上述两个原生格式，旧版James非Uvec文本格式和其它引擎以明确限制处理，不冒充完全CLHEP格式兼容。
