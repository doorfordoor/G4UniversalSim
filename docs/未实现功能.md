### 1. 根据体积分数新建材料

`mode = volume_fraction` 可以被 parser 识别，但 `MaterialFactory` 当前会抛出：

```text
volume_fraction mode is reserved but not implemented
```

所以体积分数混合材料目前属于预留功能，不能作为可运行配置使用。

### 2. gdml输入实现和stl输入实现

来自 `config/geometry/gdml_import.ini`：

```ini
[gdml]
file = geometry/model.gdml
world_name = world
sensitive_volumes = SV1, SV2
bias_volumes = Shield1
```

注意：
    ①当前 `GDMLTemplate` 只创建 placeholder `VolumeNode`，`VolumeBuilder` 未真正调用 `G4GDMLParser`。这是实验性/未完整实现功能。
    ②stl输入实现为规划中功能，没有创建接口。

### 4. 多线程输出未完全安全实现

`OutputManager` 不保证线程安全。当前设计倾向每个 worker 独立输出文件，例如 `_t0`、`_t1`，后续用 `merge_outputs.py` 或 `mergeHistograms` 合并。

### 5. Geometry创建中的trapezoid只有接口，没有实现

`trap` / `trapezoid` 当前只被 `ParseShape()` 识别，`VolumeBuilder` 没有创建 `G4Trap` 的实现。不要在配置文件中使用，否则构建几何时会失败。
