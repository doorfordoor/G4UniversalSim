# 配置撤销、自动保存与异常恢复（F5）

当前为实施候选，完整验收状态以 [ROADMAP](ROADMAP.md) 和根目录 [STATUS](../STATUS.md) 为准。

## 编辑范围

撤销/重做保护主项目的 Project、Configuration 编辑内容，包括运行参数、材料与组分、几何体/层/布尔、Source、Physics、Scoring，以及尚未通过校验的原始输入。向导成功应用为一个整体修改。独立扫描、屏蔽场景表单和未应用的向导草稿不属于主项目保存范围。

语言、主题、导航、选择行、3D 相机、日志及运行结果不属于配置修改。生成运行包、运行仿真、保存文件、复制历史包等磁盘或进程动作不会因为撤销而反向执行，也不会删除既有产物。

## 撤销与普通保存

编辑菜单及工具栏提供撤销/重做；主项目编辑控件内的快捷键与右键菜单使用同一配置历史。连续同字段输入可合并，保存、结构操作、失焦和撤销会切断合并。撤销后再修改会清除重做分支。

标题中的星号表示主项目还有未保存内容。普通保存只有在原子写入成功后才更新保存点；自动保存到恢复目录不等于保存了原项目。项目 JSON 格式升级为版本 7，补全材料文档、完整几何来源和原始编辑草稿，继续读取已知版本 1–6。未知字段、未来格式、冲突、重复 JSON 字段及非法类型仍拒绝；不支持的物理输入不会因此变成可运行配置。

编辑历史默认保留最多 100 个操作，前后快照的编码载荷总预算为 32 MiB；这不是整个应用进程内存上限。过大的单次修改必须明确失败并保持原状态，不能悄悄变成不可撤销操作。只保存当前编辑内容，不把完整撤销栈写入项目或恢复文件。

打开项目先检查完整快照容量，再切换编辑内容；后期历史重置失败时恢复原视图与历史。历史已经发布而状态通知失败时，保留新项目、路径和历史的一致性，并显示通知错误，不能把已经打开的新项目误报为未打开。

若界面更新和回滚同时失败，应用保留最后一次已确认快照，并暂停编辑、保存、生成、运行和正常关闭。使用“编辑 → 恢复最后一次已确认的编辑状态”；仅在重新投影与快照一致后解锁，恢复失败继续保留快照。非法 seed 等原始输入在生成入口仍按原文校验，不能被同步清空后当作默认值运行。

## 自动保存与恢复

每个应用会话在用户数据区拥有独立恢复文件，不写入源配置、原项目或运行输出目录。未命名项目同样保护。编辑后短暂合并写入，持续输入也有最长等待间隔；状态栏分别显示待保护、已更新和失败。写入失败保留上一次有效文件。

启动时或恢复菜单可以查看未被活跃窗口持有的恢复副本。另一个窗口仍在编辑的副本受系统文件锁保护，不以时间超时或 PID 猜测接管。可以恢复、留待以后或明确丢弃所选副本；关闭恢复对话框等于暂不恢复。损坏、不支持或超限的副本显示原因，不能半载入或静默删除。

恢复进入未命名、未保存的编辑副本，原项目路径只作为来源提示。原件和外部材料/几何变化时，保留旧草稿并提示重新核查。保存恢复后的工作需要明确选定文件；不会自动覆盖原项目。

恢复和撤销均直接投影已捕获的内容，不重新读磁盘覆盖材料或几何草稿。此前的校验、Inspect、后端几何请求和生成包绑定会失效；恢复不启动任何程序，也不恢复旧运行成功标志。继续运行前必须重新校验、生成并走正常运行入口。来源内容、配置校验或撤销一致性都不是物理正确性的验证。

## 开发接口与验收边界

无 Qt 的 `core/edit_snapshot.py` / `core/edit_transactions.py` 提供完整快照与 `EditSession`：候选修改、版本检查、提交、撤销、重做、保存点及失败回滚。窗口和未来 K1/L1 自动配置操作复用同一接口；运行期 EffectiveConfig revision 与本地编辑 revision 含义不同，不可混用。

`core/workspace_recovery.py` 只负责严格版本载荷、文件原子性与会话锁，Qt 控制器负责定时写入及恢复交互。材料/几何的已捕获原文使用统一 parser 的文本入口重建来源诊断；读取失败不能伪造成成功的空文件。

恢复文件中的诊断列表只是显示缓存；清空列表不能解除源文件未知字段和不可编辑几何的限制，必须从同一份捕获原文重建。恢复写入拒绝迟到的旧 revision、同 revision 的不同载荷及已退役 revision 的再次发布。项目来源 SHA 来自实际读取的字节或本次原子发布的临时文件字节，不把之后外部改动归为本次读写。

实施范围和逐项验收要求见 [F5 协作约定](collab/inbox/20261030-2155-astra-f5-execution.md)，实际前端设计建议见 [DeepSeek 回信](collab/outbox/20261030-2155-deepseek-f5-design.md)。核心故障注入、真实子进程异常终止、Qt 自动测试、原生窗口观察、真实 Geant4 运行与物理基准必须分别记录；尚未取得的证据不得由其他层级替代。
