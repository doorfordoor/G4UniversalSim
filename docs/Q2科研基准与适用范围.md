# Q2 科研基准与适用范围

本文是 Q2-1…Q2-5 已交付科研证据的**使用入口**，不是新的物理验证，也不扩大任何
已签收的适用域。它只回答三件事：这些量是什么、独立参考核到了哪里、原始输入/比较器/
证据在哪里。科学结论以各病例的冻结合同与最终验证记录为准；本文与旧记录冲突时，
以冻结合同为准，并保留旧失败记录。

**使用边界**：所有独立科学运行均绑定 Windows Release 产品
`864bc036…` / exe `f8a8119d…` / Geant4 `11.3.2`；不得把本文数值当成 Linux 或
Geant4 11.4 的证据。代码内部自洽（CSV/hits/scorer 互相对账、run summary 成功）
不等于独立物理验证；`limited` 表示观测限制或未获独立证明，不是“未发现问题”。

## 1. 四量定义与统计口径

| 量 | 实现逐事件估计量 | 单位 | 归一化 / 权重 / 质量体积 |
| --- | --- | --- | --- |
| 吸收剂量 Dose | `D_e = Σ w·edep[J] / m_kg`，raw 取 `w=1`（`DoseScorer.cc:71,89-105`：先按事件累计沉积能 MeV→J，再除本体质量 kg；跳过 `edep==0`） | Gy | 质量 `GetMass(true,false,步前材料)`；CSV 输出 run 累计量 `D_tot=Σ_e D_e`，`mean_per_event=D_tot/N` |
| 注量 Fluence | `L_e = Σ w·stepLength`（track-length），raw 取 `w=1` | mm⁻² | `Φ_e=L_e/volume_mm3`；仅 daughter-free 敏感 solid；CSV 输出累计 `Φ_tot=Σ_e Φ_e`，`mean_per_event=Φ_tot/N` |
| LET | `wl=w·l`、`wSl=w·l·S`、`wS2l=w·l·S²`；`S` 为电子阻止本领 | keV/µm | `LET_t=ΣwSl/Σwl`（径迹平均）、`LET_d=ΣwS2l/ΣwSl`（剂量平均）；**比值量不再除 N** |
| 位移损伤剂量 DDD | `ddd_e=lengthMm·NIEL·100/volume_mm3`；`lengthMm=w·stepLength` | MeV/g | 表外能量长度单列 `out_of_range_track_length_mm`，不计入；CSV 输出累计 `DDD_tot=Σ_e ddd_e`，`mean_per_event=DDD_tot/N` |

表内 `D_e/Φ_e/DDD_e` 是**逐事件估计量**；各 CSV 的 raw/weighted 列写 run **累计量**（Σ 事件贡献），`scorer_statistics.csv` 的 `mean_per_event` 才除 `N`；LET_t/LET_d 是全事件加权矩之比，**不除 N**。因此“总量”和“每事件均值”是两个字段，引用时必须写明是哪一个；`raw` 与 `weighted` 也分开引用。

统计不确定度一律按事件矩计算（`docs/输出数据契约.md` 的 A3 节）：

- 总量 `R² = S2/S² − 1/N`；`N` 为 `G4Run::GetNumberOfEvent()`，**包含零贡献事件**；
  `entries` 才是非零贡献事件数；N<2 → `insufficient_events`，零分母 → `undefined_ratio`，
  零分子 → `zero_total`，其余为 `approximate`。
- 比值量（LET_t/LET_d）用一阶 delta 法：`R² = S2_B/B² + S2_A/A² − 2·Σab/(A·B)`；
  LET 输出 CSV 已含两组交叉矩，可从公共 CSV 独立重算；`scorer_statistics*.csv` 的
  ratio 行不含 sum/sum_sq，不能据它反算交叉项。
- 多线程合并先对 `sum/sum_sq/den/cross/entries` 求和，`N` 取 run 完成的实际事件总数；
  不得平均 worker 误差，不得把“文件缺失”当零误差。
- 上述只描述抽样波动，不含截面/材料/NIEL 模型等系统误差；`weighted` 只在线性量上有
  直接解释，偏置权重路径需同时有 analog 对照和步长检查。

## 4. 限制清单（必须随结果一起引用）

- **LET v1**：完整强子混合谱下 100 MeV `LET_d−LET_t` 相对差 21.06 %（>5 %）**失败保留**；
  v2 的 EM-only 通过不能外推到该物理列表，也不能据此宣称强子混合 LET_d 已验证。
- **DDD**：普通 hits 会省略零沉积步且不输出步平均动能，因此“逐步完整折积”不可恢复；
  修订后比较器为 limited（6 项），先前的区间“证明”已撤回并归档；两例参考通过只说明
  有限路径下与表折积一致，**未证明后端结果缺陷，也未证明完整路径**。
- **NIEL 表**：结构/算术通过不等于表物理评价通过；95 MeV·mb 是未核实假设输入，
  ASTM/SR-NIEL 原值、模型版本与能量相关形状未独立对齐。
- **Q2-5**：原 `factor=10` 病例实测剂量比 0.4058（低 59 %），该失败保留且在验证域外；
  r2 仅 `factor=1.2` + 靶内 `max_step=0.01 mm` 的单病例通过，且**无效率收益**，不构成
  通用生产算法修复；普通运行优先 analog。
- **统计**：Q2-4 覆盖结论只针对已检查分布与样本；预注册显著/兼容不等于全局无偏；
  重尾/大权重下批均值正态近似可能不成立。
- **平台**：全部独立科学运行 Windows/G4 11.3.2；不代表 Linux、11.4、云 CI 或其它
  材料/能量/几何。
