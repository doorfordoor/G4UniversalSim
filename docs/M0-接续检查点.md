## 当前阶段：交互命令失败收尾

发现 `SessionStart()` 返回后仅检查输出写入故障，材料/输出 Messenger 把异常转为 Geant4 warning 时可能误报成功。已在 `main.cc` 增加 `--ui-session csh`、会话结束失败计数检查、非零退出、失败摘要，以及 `interactive_command_failure_kind/message`；无 macro 时保持 `macro_execution_status=not_run`。真实命令行 UI 定向回归位于 `scripts/test_interactive_commands.py`，并已加入统一测试入口。首次 Release 构建和定向脚本通过；统一回归报告待补。

本变更链路：CLI 解析 `--ui-session csh` 并校验与 `--ui` 的依赖；Messenger 原有校验继续执行，收尾检查其失败记录；运行时仅在会话结束判定，不会立即停止后续命令；GUI 未增加控件，现有 external 运行路径不改变；真实 Geant4 `csh` 回归覆盖成功退出、材料错误、输出处理器异常和 CLI 依赖；支持矩阵、路线图、输出契约、测试说明及 Agent 约束同步更新。
