# M0 测试平台说明（工作区候选）

统一入口为 `scripts/run_m0_tests.py`，按 `static`、`gui`、`backend`、`integration` 四层组织现有回归。`static` 不依赖 Qt/Geant4；`gui` 需要 PySide6；`backend` 需要真实 `G4UniversalSim` 和直方图合并工具；`integration` 同时需要后端与 PySide6。也可使用 `--profile all` 或重复 `--case <名称>` 做定向复现。已配置 Geant4 的 CMake 构建注册四个同名 CTest 测试；无 Geant4 的机器仍可直接运行 static/GUI 层，无需配置 CMake。

```powershell
python -B scripts/run_m0_tests.py --profile static
python -B scripts/run_m0_tests.py --profile gui
cmake --build build_vs2026 --config Release --parallel 4
ctest --test-dir build_vs2026 -C Release --output-on-failure -L m0
```

Windows 本机若同时安装多个 Python，配置 CMake 时需显式选择已安装 PySide6 的解释器，例如 `cmake -S . -B build_vs2026 -DPython3_EXECUTABLE=C:/Users/123/AppData/Local/Programs/Python/Python311/python.exe`；否则 GUI 与集成层会因环境缺失而跳过。2026-10-04 在当前脏工作区、HEAD `018345c`、Python 3.11.9 和 Release 后端下，四层 CTest 全部通过（0 失败、0 跳过）；报告分别保存在 `D:/Temp/g4usim-m0-tests/20261004-223523-e3fe36ed`、`20261004-223524-46df1609`、`20261004-223529-254b6c8b`、`20261004-223708-5bf82f82`。这仅证明当前机器与当前源码指纹的测试覆盖，不代表干净检出或其他平台已经验收。

每个测试在子进程中运行，默认从仓库根目录启动，GUI 使用 `QT_QPA_PLATFORM=offscreen`，Python 禁止写入 `__pycache__`。测试 fixture 应自行在系统临时目录创建，不能使用仓库默认输出目录。入口将每项标为 `pass`、`fail` 或 `skip`，分别保留退出码、耗时和独立日志；JSON 报告位于系统临时目录 `g4usim-m0-tests/<本次标识>/report.json`。任一失败返回 1；无失败但有环境缺失/跳过返回 2；全部通过才返回 0。CTest 会把返回 2 显示为 skipped，因此**不能只看 CTest 的总退出码**，还须查看每组报告和跳过数。

报告另列 `untracked_source_files` 与 `tracked_source_gate`，包含被忽略但未纳入 Git index 的本地运行/测试源码。普通开发回归仍可在脏工作区运行；阶段验收须加 `--require-tracked-sources`，只要这些源码仍未纳入 Git index 就返回 1。此门槛不会自动暂存文件，也不能代替在干净检出中重建和重跑测试。

后端可执行文件的 `--capabilities` 含 `source_fingerprint`：CMake 对排序后的 `main.cc`、`src/*.cc`、`include/*.hh`、`include/Core/BuildInfo.hh.in` 和 `CMakeLists.txt` 的路径与内容计算 SHA-256，构建时写入二进制。直方图合并工具另以 `--source-fingerprint` 返回其 `tools/mergeHistograms.cc` 的 SHA-256；测试入口分别与当前工作区比对，不匹配时跳过相应用例并要求重建。`report.json` 同时记录 Git HEAD、工作区脏状态、两项源码指纹、构建配置、编译器 ID/版本、Geant4 版本编号、MT 编译状态和平台/Python 信息。2026-10-04 本机 Release 实测为 MSVC 19.51.36246.0、Geant4 1132、MT=true。源码指纹证明测试二进制对应所列源码；构建元数据有助于比对环境，但仍未覆盖全部编译选项、链接库、Geant4 数据集或物理结果等价性。
