# CSDA 射程（水）

**物理量**：初级粒子在水中停止前的平均路径长度，与 NIST PSTAR（质子）/ESTAR（电子）的 CSDA 射程比较。CSDA 射程不含核反应，因此使用仅电磁物理（`[physics] em = option4`，即 `G4EmStandardPhysics_option4`），默认 cut 0.7 mm；粒子从 80 cm 水立方体中心沿 +z 出射，逐事件累加 track 1 的步长（水的密度 1 g/cm³，cm 即 g/cm²）。

**2026-10-22 完整模式结果**：

| 粒子 | 能量 | 模拟（g/cm²） | NIST | 偏差 |
| --- | --- | --- | --- | --- |
| 质子 | 10 MeV | 0.12405 ± 0.00005 | 0.1230 | +0.86 % |
| 质子 | 50 MeV | 2.2417 ± 0.0008 | 2.227 | +0.66 % |
| 质子 | 100 MeV | 7.7639 ± 0.0027 | 7.718 | +0.60 % |
| 质子 | 150 MeV | 15.887 ± 0.006 | 15.77 | +0.74 % |
| 质子 | 200 MeV | 26.107 ± 0.010 | 25.96 | +0.57 % |
| 电子 | 1 MeV | 0.4409 ± 0.0013 | 0.4367 | +0.95 % |
| 电子 | 10 MeV | 4.986 ± 0.017 | 4.975 | +0.23 % |

质子射程系统性偏长约 0.6–0.9 %：Geant4 的 `G4_WATER` 平均激发能 I = 78 eV，而 PSTAR/ESTAR 用 75 eV。以 100 MeV 为例，阻止数 L = ln(2mc²β²γ²/I) − β² ≈ 7.85，ln(78/75) = 0.039 使阻止本领约低 0.5 %、射程约长 0.5 %，与观测一致。这是材料参数差异，不是程序错误。

**单独运行示例**（100 MeV 质子，hits 写出每一步）：

```bash
build_vs2026/Release/G4UniversalSim.exe --config scenarios/benchmarks/csda_range/example.ini
```
